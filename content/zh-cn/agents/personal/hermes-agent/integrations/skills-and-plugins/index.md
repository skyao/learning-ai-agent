## 方法文件与工具能力分别看

Skills 采用按需加载的知识文档，兼容 Agent Skills 格式。当前技能来源包括内置、外部安装和 Agent 创建，最终仍要看具体内容、依赖和运行配置。

我更关心一次成功经验如何变成稳定方法：输入缺失、审批、错误恢复和验收条件是否一起写入？一次顺利执行并不能覆盖所有分支，自动生成技能后仍需要用不同条件复验。

官方安装路径包含来源识别与扫描，但扫描不能代替对实际副作用的理解。技能更新、用户修改与正在执行的计划之间怎样传播，也需要版本记录。我希望自己的平台能解释某次任务采用了哪份方法，而不只显示一个技能名称。
