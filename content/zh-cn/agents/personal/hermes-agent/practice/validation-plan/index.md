## 先验证生命周期

| 场景 | 观察与证据 |
| --- | --- |
| 保存测试偏好后继续聊天、再新建会话 | 工具回执、文件与实际引用范围 |
| 两个 Profile 使用不同项目约束 | 配置、目录与跨域信息是否混入 |
| Cron 执行期间重启网关 | 触发身份、运行、交接与最终投递 |
| 子任务启动后台命令后结束 | 进程归属与产物是否完整 |
| 目标判定错误或预算耗尽 | 停止原因、续做与人工修正 |
| 恢复备份后运行旧计划 | 配置依赖、重复动作和历史衔接 |

这些是待执行实验。先固定稳定版本与模型，再只改变一个条件；把模型判断、工具失败和宿主可用性分开记录。与 OpenClaw 对照时使用相同资料包、权限和验收标准，并计算维护时间。
