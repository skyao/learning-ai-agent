## 分组验证

| 实验 | 观察与验收 |
| --- | --- |
| 单 Bot 完整任务 | 来源、分类、笔记和产物位置都可核验 |
| 双 Bot 交接 | 接收方是否保留来源、限制和未确认结论 |
| 共享电脑 | 两个角色能否读取同一文件或网站会话，是否发生并发覆盖 |
| 记忆纠正与复制 | 配置、历史、学习信息和计划分别带走什么 |
| 技能与演示 | 成功路径之外的缺失来源和异常页面如何处理 |
| 周期与事件 | 实际触发次数、延迟、暂停与重复效果 |
| 后台审批过期 | 动作是否执行、任务怎样标记、重试是否重复 |
| 本地命令 | 审批、目标设备、断开和重连后的真实动作 |
| 终止与重建 | 持久文件、会话、运行中任务和外部结果是否保留 |
| 模板与 Team Bot | 使用新副本或共用对象时，访问主体与记忆范围是否改变 |

Team Bot 实验只在具备相应测试团队条件时进行，不能为完成文档调研编造使用结果。

## 怎样比较

先单 Bot，再多 Bot，固定来源与产物标准。记录每次人工审批、改写、等待、纠错与可见用量，计算实际减少了多少协调工作。

我会把失败后的恢复也写下来。工具报错不自动表示没有写入，界面重新连上也不代表任务状态完整恢复。阶段性理解见 [总结](../../summary/)，实验完成后另立记录。
