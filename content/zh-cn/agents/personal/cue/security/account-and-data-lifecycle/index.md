## 帮助中心明确的范围

Cue 与 Manus 共享账号和数据，当前不支持只删除 Cue 账号并保留 Manus 账号。[账号删除说明](https://help.manus.im/en/articles/11711969-how-can-i-delete-my-account)

数据删除 FAQ 还保留必要信息可能因特定业务和法定义务继续留存的条件。因此，不能将账号不可恢复理解为所有副本即时物理清除。[数据保留说明](https://help.manus.im/en/articles/11711823-will-my-personal-data-be-deleted-after-i-delete-my-account)

## 我的理解：产品入口与数据边界不一定重合

独立应用可以共用账号，而不同配置又可能分开。此前看到的 Skills 边界便是一个例子。我需要按对象核对作用范围，不能先假定两个产品完全独立，也不能假定所有内容自动互通。

共用账号和数据同样不能直接证明，账号内每个代理能读取其他代理的所有内容。具体访问控制、记忆共享和群组权限仍需要独立证据。

## 我希望分别核对的生命周期

| 对象 | 我还需要确认的行为 |
| --- | --- |
| 单个代理 | 删除后，其职责、记忆与关联任务如何处置 |
| 邮箱与电话号码 | 停用后的来信来电、历史记录与任务关系 |
| 外部应用连接 | 撤销访问后，已取得资料和派生内容如何处理 |
| 群聊与交接产物 | 成员变化后谁仍可访问历史内容 |
| 共用账号 | 两个产品中的资源、账单和数据如何收敛 |

表中是我的后续研究问题，并不意味着当前产品已经提供每一种独立管理入口。
