这是截至 **2026-10-21** 的待实测方案，**没有安装客户端、下载模型或执行任务**。

我先固定客户端、系统、硬件、订阅、显示模型、执行模式、Brain 和工具授权。使用公开文章、虚构偏好、测试目录和可丢弃文档，目标是维护一份个人代理研究材料。

## 实验矩阵

| 实验 | 我的验收依据 |
| --- | --- |
| 云端任务 | 来源、文件与产物可核验，客户端关闭后状态可解释 |
| Personal / Hybrid | 哪些步骤依赖 Mac，何时等待和恢复 |
| 完全本地 | 实际模型、文件处理、外部请求和云端升级确认 |
| 设备断开 | 浏览器、Mac、手机分别断开时不误判完成 |
| Brain 纠正 | 来源可追溯、错误更正传播、开关与既有记忆分开 |
| 周期工作 | 背景或含对话方式、错过周期和重新启用 |
| Skills | 明确加载的方法、版本与实际分工 |
| 多路径访问 | 断开连接器后，浏览器和 App 路径怎样变化 |
| 审批与停止 | 拒绝后不继续相同动作，外部结果单独核验 |
| 用量对照 | 质量、等待、人工修改、计算与设备投入共同记录 |

## 怎样保持比较公平

先固定资料包和输出标准，再比较模型配置、记忆和执行模式。不能一边换模型一边增加连接器，还把全部收益归因于本地计算。

使用中文资料与英文资料分别核验引用和日期，保持本项目第一人称笔记写法。重复运行检查覆盖、遗漏和重复添加。

我会保存原始产物、实际差异和每次人工介入，也会跟踪失败后的恢复。结果完成后另写实践记录，再更新 [阶段性总结](../../summary/)。
