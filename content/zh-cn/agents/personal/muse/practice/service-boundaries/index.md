## 报道要点

9 月报道记录了亚马逊对 Muse 网站访问的限制，以及身份披露、凭证与用户授权方面的争议。

10 月报道记录了金融平台对外部代理的访问限制，并提及查询接口和执行资金操作之间可能采用不同边界。报道不能概括成“所有银行完全禁止所有 AI”；限制对象、接口与动作要分别核对。

## 银行线逐家补记（2026-10-13～21，2026-10-27 补记）

我在资料库补记时把 10 月报道拆到了机构一级，结论仍是「封动作、不封全部接入」，但各家口径的确定程度不同：

- JPMorgan（2026-10-13，Q3 财报会）：CEO Jamie Dimon 称不让外部 agent 进入系统为客户行动，理由是失控 agent 与责任转移；发言人向 CNBC 确认的边界是阻止第三方以收集客户银行凭证的方式登录，同时支持经客户授权的开放银行数据共享。读侧（经 Plaid 等聚合器读余额）与动钱侧（发送资金、支付账单）在此分开。
- Schwab（2026-10-14 财报会重申，2026-10-16 Bloomberg Television 点名 Muse）：CEO Rick Wurster 的原话是，不希望客户把密码交给 Muse 后由它代为行动，「我们无法控制它，客户也无法控制它，出了问题谁担责？」；他自述的内部周报显示，大 agent 每周被拦截的次数在数十次量级。替代路径是正在准备的 MCP 服务器：外部模型可在受控认证下看余额、做研究，但不能动钱；同时推自家助手 Charley（2026-09-30 发布，初期限行政与信息类任务）。
- Citi 与 Bank of America（同期财报会周，转述层）：Citi 跟进限制 agent 进入客户账户，CEO Jane Fraser 在 Sibos 会议上的口径是身份、认证与监管三件事钉死之前，agent 不应从回答问题走到执行支付；Bank of America 的 CEO Brian Moynihan 称正在制定 agent 授权支付的担责协议，属方向表态，未见已公布的封堵细则。
- 加拿大（2026-10-20/21）：RBC 的 CEO Dave McKay 称正在考虑限制 Muse 访问客户银行信息，明确「尚未定案」，不能列为已封堵方；BMO 的 CEO Darryl White 在 Toronto Global Forum 上劝阻消费者向 AI agent 提供银行凭证，属公开劝阻与原则表态，未见针对 Muse 的具体拦截政策。
- Meta 一侧的回应方向（转述层）：Meta 正在与 Sierra 合作开发 Personal Agent Protocol 标准，意图让企业能识别某个 agent 正在代表某位客户行动；该标准未见正式发布口径，我不把它当作已落地的通行证。

这组材料修正了我对[理财功能评测](../money-review/)的理解：评测清单里的支出追踪、订阅审计、脱敏分析多在银行容忍的读侧，而资金搬运、代付账单正是银行明确封堵的动作。把两者混为「理财功能可用」会高估 Muse 在银行场景的实际权限。触发讨论的背景之一是 Apollo 首席经济学家 Torsten Slok 在 2026-09-27/28 的笔记：agent 可能把客户从约 0.1% 的支票账户利率批量搬向 3.3%～5% 的金融科技产品；这是经济学家的警告，不是银行政策，我把它记在背景层，不与封堵口径混排。

## 我的理解：把失败定位到执行链的具体边界

从平台和 Agent 开发角度，我需要区分模型规划、工具执行、用户授权和服务方许可，否则一次失败很容易被笼统归入“Agent 能力不足”。下面是我准备采用的分析口径，尚无自己的统计结果。

| 失败来源 | 我希望保留的证据 |
| --- | --- |
| 理解或规划 | 原始要求、遗漏约束、选择的动作 |
| 工具执行 | 调用参数、工具错误、页面或接口状态 |
| 用户授权 | 所需权限、现有授权和审批状态 |
| 服务方拒绝 | 拒绝信息、访问对象与适用接口 |
| 外部条件变化 | 商品、预约或业务状态的变化时间 |

用户授权与服务方许可分别约束不同边界。我更关心产品能否准确识别拒绝原因、保留已完成的工作，并说明接下来需要谁处理。这样才能把失败反馈转化为平台改进或 Agent 逻辑调整。

## 资料缺口

2026-10-27 的补记把银行线拆到了机构一级（日期、点名对象、读侧与动钱侧的边界），但 JPMorgan、Citi、Bank of America、RBC、BMO 的口径仍为转述层，Schwab 口径也只到 Bloomberg 转载全文一级；我还没有逐家以原始声明和账号实测复核每个接口和动作的当前状态。后续仍需补上机构原始声明、Schwab MCP 服务器的上线时间与准入条件、RBC 是否最终跟进，以及 Poppy 协议的正式发布；一次工具失败也不足以证明普遍政策。
