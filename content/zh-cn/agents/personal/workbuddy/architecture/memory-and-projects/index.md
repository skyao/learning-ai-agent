## 三条上下文路径分开

内建记忆帮助说明每晚从会话整理事实、偏好与跟进信息，后续任务使用相关背景，并提供查看、更正、删除与关闭。项目则组织共享指令、技能、连接器与资产，资料库通过检索参与任务。

腾讯云数据库另有 Memory Hub Proxy 接入说明，需要独立部署和配置，不能将它当成内建记忆的默认底层实现。该指南还存在表格引用其他客户端名称的情况，实际路径需要复核。

我关注从来源到实际使用的链路：事实更新何时进入下一轮，个人与团队信息是否混入，删除后有哪些派生状态仍存在。记忆可编辑、资料可检索与上下文正确使用是三个不同验收点。
