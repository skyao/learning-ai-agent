我把 Claude Duet 加入第一批 Personal Agent 调研：它把主动发现、持续跟进和用户决策放到独立应用中，适合与 Muse、Dots 和 Claude Cowork 分别对照。

Duet 与 Cowork 是 Claude 体系中两种相关的产品形态：前者侧重主动、持续的委托，后者侧重对话中的知识工作执行。两者共享部分账号能力，持续执行和资源访问仍各有条件，详见 [Duet 与 Cowork 的关系及差异](product/positioning-and-cowork/)。

本轮阅读截至 **2026-10-23（北京时间）**，为公开资料调研与个人分析，没有新增账号、设备或部署实测。
