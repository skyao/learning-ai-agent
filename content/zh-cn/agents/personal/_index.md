我希望通过调研个人智能体（Personal Agent），理解个人上下文、持续执行和用户授权如何组合成长期服务于一个人的系统。这些问题也与我正在做的 Agent 运行平台和开发工作直接相关。

这里持续记录产品动态、资料阅读、架构比较和实践中的发现，逐步沉淀自己的理解。

## 调研入口

- [业界产品清单与调研计划](research-list/)：16 个主要对象已完成公开资料调研；第一批 8 个（含 WorkBuddy、Duet），第二批 8 个（含 Personal Computer、Cowork），分别保留核验日期。
- [Meta Muse](muse/)：已有介绍、架构、安全与分析素材。
- [OpenAI Dots](dots/)：产品、任务与记忆、执行环境、安全治理及阶段性学习总结。
- [Manus Cue](cue/)：代理身份、团队交接、通信资源、钱包权限与阶段性学习总结。
- [Google Gemini Spark](gemini-spark/)：Task 入口演进、个人上下文、计划、Google 应用生态与云端 / 本地执行边界。
- [Grok Bot](grok-bot/)：长期角色、共享云端电脑、团队身份、Skills / Routines 与授权控制。
- [OpenClaw](openclaw/)：Gateway / Node、会话路由、记忆、Automations、自建运维与信任边界。
- [WorkBuddy](workbuddy/)：个人办公、项目记忆、本地 / 云端执行、定时任务、连接器与权限范围。
- [Claude Duet](claude-duet/)：主动发现、云端持续工作、账号记忆、任务验收、钱包批准与数据边界。
- [Hermes Agent](hermes-agent/)：Profile / Bot、内建记忆、经验技能、目标推进、Cron 与自建维护。
- [Copilot Autopilot](copilot-autopilot/)：从 Scout 到云托管代理的演进、组织身份、Microsoft 365 上下文与治理。
- [Poke](poke/)：消息入口、账号状态、Recipes、MCP / API、人工协助与授权。
- [Lindy](lindy/)：个人与团队记忆、Routines、Skills、演示学习、Guardrails 与共享产物。
- [Kimi Claw](kimi-claw/)：OpenClaw 产品化、云端与设备路径、群聊协作、技能同步与升级恢复。
- [Perplexity Personal Computer](personal-computer/)：Computer 产品谱系、Brain、周期任务、本地 / 混合运行与 SPACE。
- [DeepSeek Harness](deepseek-harness/)：个人工作代理与可组合运行时、会话事实、调度、Goal 及执行控制。
- [Claude Cowork](claude-cowork/)：统一入口、云端与桌面桥接、Projects / Memory、排程、工具权限及可观测性。
- [第一批八个产品的阶段性比较](first-batch-summary/)：公开资料调研已完成，整理共同问题、路线差异与下一阶段验证方法。
- [第二批八个产品的阶段性比较](second-batch-summary/)：补充自建、消息、团队与个人电脑执行路线，整理状态、执行与授权的比较认识。
