## 我能确认到哪一层

官方账号文档把 Memory 作为持久对象，产品强调个性化；接入邮件和日历则提供具体来源。本轮没有找到足以确认完整写入、检索、冲突处理和存储拓扑的公开技术说明。

我因此先记录三条不同路径：消息历史、连接服务的当前信息和代理保存的记忆。它们可能支持同一次回答，但更新和删除不一定同步。

下一步会先让系统记住一个虚构偏好，再更正有时效的测试事实，检查新任务使用的证据。自然语言中声称“已记住”还不等于可复核的写入回执；我也不会借用外部评测中的概括补出内部架构。
