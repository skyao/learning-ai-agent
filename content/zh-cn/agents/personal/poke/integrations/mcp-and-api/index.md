## 两种开发接入方向

MCP 让 Poke 调用服务工具；Poke API 让外部程序向助手发消息。API 文档说明请求按正常消息处理，可能使用已连接的邮件、日历和工具，因此触发密钥具有实际委托影响。

本地 MCP 通过隧道暴露可达入口，隧道进程需要持续运行。这不是将本机所有应用自动变成云端能力；服务与网络的可用性仍是依赖。

当前 API 区分旧 V1 与 Kitchen 新 V2 密钥及入口，不能把旧示例原样当成当前流程。我这里只做接口阅读，没有创建密钥或连接服务。后续会使用无副作用工具检查触发来源、重复请求、授权撤销和最终回执。
