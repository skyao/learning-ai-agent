## 上下文与执行通道分别看

会议库支持录制、转写和按访问范围提问，之后再形成待办或工具更新。电话则进一步进入与外部联系人交互的路径，不能只把它当成另一种文本输入。

MCP 帮助要求公网可达的 HTTPS streamable-HTTP，连接时读取工具目录，只导入所支持的 schema。工具报告数量与实际可用数量可能不同，因此“连接成功”还要检查具体动作。

对平台开发，我希望每次执行保留通道、账号与资源标识。通过连接器、浏览器、自写 API 或电话完成类似目标，权限、结果证据与可撤销性都不同。本轮未创建号码、录制会议或连接 MCP。
