## 先使用两个测试成员

| 场景 | 观察点 |
| --- | --- |
| 同一请求分别从 DM、Web 与共享 Slack 发起 | 来源、审批与输出范围 |
| 个人和团队同名技能 | 优先级、停用与版本 |
| 测试事实被纠正或删除 | 文件、记忆与后续任务 |
| 共享连接被轮换或撤销 | 实际主体、当前运行与未来计划 |
| 额度不足与高用量提示 | 谁有权继续、暂停与恢复 |
| 产物由私有变公开再撤回 | 可访问者与敏感内容检查 |

电话和会议能力先核对测试条件，不联系真实外部对象。所有实验尚未执行；以相同材料和完成标准保存证据，再比较个人助手与团队共享带来的收益和成本。
