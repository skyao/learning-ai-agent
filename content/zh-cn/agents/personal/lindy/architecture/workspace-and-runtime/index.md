## 我能确认的产品对象

官方当前入口围绕个人聊天、共享线程、文件、会议、技能和 Routines 组织工作。我把它理解为围绕人和团队形成的持续工作空间，不从页面示意图推断底层 VM 拓扑。

安全页描述云端基础设施和持续运行，但未公开完整调度与隔离实现。对我做平台，用户看到的长期助手需要与单次运行、文件版本及工具身份关联；这些关系可以用来解释失败与恢复。

后续会用相同项目在私信和共享线程中各执行一次，检查来源、输出可见性与工具账号。如果一次任务转到浏览器或自写 API 路径，还要确认原先约束怎样延续，不能只按工作空间名字判断隔离。
