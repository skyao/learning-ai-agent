## 文件可见让纠错有了入口

当前 Memory 帮助将它描述为可浏览、编辑和保留版本的文件空间，并区分 Personal、Team、System。个人资料按工作空间划分，团队文件由管理员维护，系统内容则内置只读。

这让我更容易提出具体实验：修改一个错误事实后，新任务实际读到了哪个版本？删除文件后，运行中上下文和其他派生状态是否仍受影响？可编辑文件本身不能证明检索和使用一定正确。

我会把长期事实、方法与交付物分开记录。即使它们都出现在同一个文件浏览器，也需要分别处理来源、优先级、权限和过期。这里没有实测多工作空间隔离，也未将厂商“不会泄露”的表述升级为独立验证。
