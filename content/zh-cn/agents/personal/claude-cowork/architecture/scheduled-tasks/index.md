## 我如何理解定时任务

当前帮助提供周期任务、独立执行会话，以及暂停、编辑、删除和立即运行等管理动作。它让我可以把重复的信息整理交给系统，但这仍然需要一个稳定的任务契约：输入是什么、什么时候执行、允许改变哪些资源、失败后如何处理。

我将“按时发起一次任务”和“长期负责一个目标”分别记录。前者可以每次重新检索，后者还需要持续维护进度、识别变化并调整下一步。公开功能说明不足以证明后者已经可靠实现。

## 关机以后能否继续，需要看依赖

当前多端文档说新的 Pro / Max 任务在云端执行，纯云端任务可以在电脑关机时继续。本地文件和应用访问依赖设备连接。

但定时任务帮助的创建步骤仍保留“需要本地文件或应用的任务只会在本地运行”的表述。这与新云端默认、通过桌面访问本地资源的描述存在需要解释的差异。它可能涉及旧任务或某类资源路径，官方页面没有在该句中完整说明。我保留为待实测，暂不替官方补出统一实现。

## 我的运行验证清单

| 场景 | 我想确认的行为 |
| --- | --- |
| 只读公开网络资料 | 关机后是否按期执行，结果如何通知 |
| 读取授权本地文件 | 设备离线时等待、跳过还是报错 |
| 使用已登录浏览器 | 不同浏览器路径的在线要求 |
| 等待用户审批 | 是否过期，下一次执行是否重复同一动作 |
| 取消或删除计划 | 已开始的运行是否同时停止 |

我还会检查重复执行、错过触发和恢复后的幂等性。对运行平台而言，计划定义和每次执行必须有独立身份，否则很难解释某份结果来自哪次运行，以及停掉计划以后为什么还有一个任务在继续。
