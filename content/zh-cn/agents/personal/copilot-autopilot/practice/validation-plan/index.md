## 先验证产品路径

| 场景 | 我需要的证据 |
| --- | --- |
| 确认新版入口与身份 | 租户、开放条件、实际执行主体 |
| 电脑关闭后继续云端研究 | 会话状态、完成时间与资源依赖 |
| 多日跟进测试项目 | 目标变化、资料更新与停止条件 |
| 修改会议或列表前确认 | 批准对象、最终修改与撤销行为 |
| 变更角色或资源权限 | 运行中、派生工作与下次触发结果 |
| 对照旧 Scout 桌面任务 | 环境、文件和模型配置差异 |

这些实验尚未执行。私人预览条件具备前，先保留官方说明和问题；不能把未获得账号的功能判定为不存在，也不把厂商示例写成我的工作收益。
