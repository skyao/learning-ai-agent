## 四条路径分别理解

| 路径 | 运行与责任 |
| --- | --- |
| 一键云端 | 平台部署 OpenClaw，个人设备作为入口 |
| 关联已有实例 | 用户自己的 OpenClaw 通过插件接入 |
| Desktop | 专门指南描述本机部署，可迁移既有配置 |
| Android | OpenClaw 在手机终端内运行，需要设备与网络 |

本机运行不等于模型本地推理，也不能推定所有上下文只在设备处理。Android 的后台常驻还依赖网络、电源和系统限制。

对平台开发，我希望同一账号下每个执行器都有明确归属、健康状态和资源范围。设备不在线时，目标可以保留，实际动作却不能假装仍可执行。群聊加入多个设备以后，这种区分尤其重要。
