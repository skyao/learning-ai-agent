本页只回答一个问题：**哪些东西常被叫 Agent，但在这份笔记里不算 AI Agent。** AI Agent 的定义和四个关键要素在 [什么是 AI Agent](../what-is-ai-agent/)。缺任何一条，就降级为模型能力、助手或前身等。

## 有哪些东西被称为 Agent ？

AI 中很早就有 Agent 了，远在 LLM 和本笔记关注的 AI Agent 出现之前。

| 谁在说 | 他所谓的 Agent | 宽到什么程度 |
| --- | --- | --- |
| 人工智能教材（如 Russell & Norvig） | 能感知环境、按性能度量选择行动的东西 | 恒温器、棋手、机器人都算 |
| 1990 年代智能体文献（BDI 等） | 有信念、愿望、意图的软件实体 | 决策核是符号规划或规则，不是 LLM |
| 产品营销 | 任何「比较能干活的 AI」 | 聊天机器人、一次函数调用、行级补全都可能被叫 agent |
| **本笔记** | **LLM 驱动的多步执行系统** | 刻意收窄，否则 AI Agent 历史会变成一部 AI 通史 |

本笔记把更老的传统只当作[前传](/timeline/before2022/)，AI Agent 主线从语言模型能多步决策之后才开始。

## 对话不是 Agent

**ChatGPT 式单轮/多轮问答。** 有 LLM，也可能多轮，但没有对外部世界采取行动的循环。使用者和模型说话，模型再生成文本。这是对话接口，是 2022 年的产物，不是我们定义的 AI Agent。

缺的是「对环境行动」和由此而来的反馈循环。多轮聊天只是上下文变长，不是多步执行。

## 单次行动不是 Agent

**「帮我查天气」→ 模型选了 `get_weather` → 返回气温。** 有行动，没有迭代。

**Function Calling / 工具接口本身** 也不是。它是模型层能力，是地基：没有它，后面的循环搭不起来。单独拿出来，仍不是一个系统。缺的是多步，以及根据上一次结果再决策。

## 改了环境，也不一定是 Agent

**行级 Copilot 补全** 会插入代码，确实碰到了环境。但它没有「完成一个目标」的循环：没有计划、没有看测试再改、没有做到某个结束条件。本笔记把它标成否，同时承认存在 **Copilot → Agent** 的演化，但他们不是同一种东西。

## 决策核不是 LLM，也不算本站主线

**传统符号 Agent、BDI、纯强化学习游戏 Agent** 在教材和论文里都叫 agent。它们能感知、能行动、也能循环。但下一步不是语言模型选的。这份笔记要学的是 2022 年之后那波 **LLM Agent**，所以它们不算主线对象，只作为历史渊源。

**机器人、自动驾驶** 同理：是相邻领域，物理世界另一套体系，不并入这份学习笔记的时间线。

## 四个有一个不满足就不算 AI Agent

完整表在 [调研方法](/timeline/overview/research/#agent-边界清单)。是的一侧在 [什么是 AI Agent](../what-is-ai-agent/)。

| 形态 | 算不算 | 缺哪一条 |
| --- | --- | --- |
| 单轮对话 | 否 | 无行动循环 |
| 单次工具调用 | 否（背景能力） | 无迭代 |
| Function Calling / 工具接口 | 否（模型层） | 不是系统 |
| 行级代码补全 | 否 | 无目标循环 |
| 传统符号 Agent / 纯 RL 游戏 Agent | 否（本笔记主线） | 决策核不是 LLM |
| 机器人 / 自动驾驶 | 否（相邻领域） | 物理世界，另一套体系 |
