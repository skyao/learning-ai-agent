## 当时解决了什么问题

2023 年 AutoGPT 证明舆论要「给一个目标让它自己转」。编码这条线缺一个能看懂的产品：不是补全下一行，而是在仓库里设环境、复现、改代码、跑测试。Devin 把 Copilot 式副驾驶叙事推成「整份工作交给它」。SWE-bench 给了它一个可以引用的数字，而不只是演示视频。

按 AI Agent 定义，Devin **是** Agent：LLM 决策、在沙箱里行动、看测试与终端回执再决定。自主度高于 IDE 里的补全，仍有人下任务、看过程、收 PR——弱自主，不是无人值守员工。

## 对后续 LLM 与 Agent 的影响

「AI 软件工程师」从此变成品类名。Cursor、SWE-agent、OpenHands、后来的 Claude Code / Codex，都要在这条舆论里表态：全自主云端，还是人在环路的编辑器。Devin 的演示把期望拉到「能上岗」。

13.86% 要连着读：570 / 2,294 题，不是全量；厂商自报；agent 设定与当时公开的 assisted / unassisted 检索基线**不是严格同口径**；独立复现当时稀缺。热度像 2023 年的 AutoGPT——定义话题，不定义上限。人在环路的 IDE 助手往往更早上日常，留存也更高。引爆型事件要等第三方完成谓词；这一页记下的是口号先于尺子。
