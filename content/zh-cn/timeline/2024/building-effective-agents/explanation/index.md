## 当时解决了什么问题

2023–2024 的框架营销倾向于：多 Agent、图越复杂越先进。生产里大量任务其实是固定步骤：抽字段、调两个 API、写摘要。把这些做成「自主 Agent」会多付延迟、钱和失败模式。这篇博文用厂商自己的客户实施经验，把冷水泼在「一切都上多 Agent」上。

按文中定义，工作流往往**不是**本站 AI Agent：路径预写死，模型只在节点上生成。自主 Agent 才接近本站定义。两者可以组合，不要用同一个词。

## 对后续 LLM 与 Agent 的影响

2025 年的 Claude Code / Codex 是厂商托管的自主循环，看起来和「少用框架」并不矛盾——循环被收进运行时，而不是让每个应用自己叠一层编排库。博文的遗产是设计原则：先工作流，评测不够再用 Agent。读 2024 年底的架构选择，这篇比 CrewAI / AutoGen 的发布会更接近后来留下的口味。
