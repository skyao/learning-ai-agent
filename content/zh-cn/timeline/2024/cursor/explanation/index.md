## 当时解决了什么问题

Devin 把期望拉到「整份工程交给 AI」。真实开发者的日常是：在仓库里改几处、看 diff、跑测试、提交。Cursor（以及同期的 Copilot Chat）把模型嵌进这套已有动作，而不是要求人改用一个新的自主工人。人在环路：模型建议，人拍板。失败成本是一次撤销，不是一次静默的错误 PR。

按 AI Agent 定义，2024 上半年的 Cursor **大多还不是**完整 Agent：Tab 补全和单轮编辑缺少「对环境行动、按反馈再决策」的长循环。它是 Agent 史里必须记的引爆，因为**使用方式**改变了——决策核心进了 IDE。更像 Agent 的多文件循环（后来叫 Composer / Agent）是随后加上的，不要回填成上半年已经有。

## 对后续 LLM 与 Agent 的影响

2025 年的 Cursor Agent、Copilot Agent Mode、Gemini CLI，都是这条「在编辑器/终端里委派」的加长版。全自主云端工程师没有消失，但日活和习惯长在人在环路这边。定义允许弱自主；这是留存先起来的形态。评测上 SWE-bench 衡量的是少人干预的闭环；产品留存衡量的是另一件事。两条尺子不要混用。
