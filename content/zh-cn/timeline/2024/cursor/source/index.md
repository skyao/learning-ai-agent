## 当时能看见的产品主张

Cursor 是 VS Code 分支上的编辑器。2024 年开发者实际在用的，主要是：

- **Tab 补全：** 按当前文件与周围上下文建议下一编辑，人接受或改。
- **对话与行内编辑（Cmd/Ctrl+K 一类）：** 用自然语言改选中代码或提问，diff 留在编辑器里由人确认。
- **代码库问答：** 对当前项目提问，检索/索引帮助模型看见多文件，仍是人发起、人收场。

付费订阅、自带或自备模型密钥。宣传强调「在你写代码的地方」而不是另开一个云端工程师控制台。

## 当时不是什么

上半年的 Cursor **不是** Devin 那种「丢一个 issue 等它自己开 PR」的全自主云端工人。多文件自主循环（后来叫 Composer / Agent）是更晚的产品层。把 2024 年中的 Cursor 写成已经等同于 2025 年的 IDE Agent 模式，是时间错位。
