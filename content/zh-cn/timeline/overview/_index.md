先把工作定义钉住，再读时间线。入门：[什么是 AI Agent](/definition/what-is-ai-agent/)、[什么不是](/definition/what-is-not-ai-agent/)。

按年学 Agent，是为了看见前提，不是为了背事件。

AI Agent 不是 ChatGPT 之后突然冒出来的产品名词。它是「语言模型开始能多步决策」之后，工具、环境、协议、评测逐步咬合出来的软件形态。每年问同一件事：**这一年 LLM 多了什么能力，Agent 因此才能做什么，什么仍然做不到。**

本栏是学习入口。定义、边界、里程碑类型和采信门槛见 [调研方法](./research/)。论文、产品、协议、基础设施的精读仍在其他栏目，时间线只负责把它们放到「何时、为何此时可能」。

## 这条时间线在讲什么

对象收窄为 **LLM Agent**：以大语言模型为决策核，能在多步循环里行动、看反馈、再决策，直到目标完成或失败。单轮问答、一次工具调用、行级代码补全，都不是这里的主角；更早的符号 Agent / RL Agent 只作为 [2022 年之前](../before2022/) 的前传。

所以 Agent 史不等于 LLM 史。模型年年在涨，写进年份页的只是**改写了 Agent 可能性**的那些变化：推理能不能多步、工具接口是否稳定、上下文够不够撑住一次长任务、能不能看见屏幕和代码库。

和 LLM 的关系，可以看成一条脊梁：

| 阶段 | LLM 给了什么 | Agent 因此是什么 |
| --- | --- | --- |
| 前传 | 还不能当可靠规划器 | 符号 / RL Agent，只作渊源 |
| 底物 | 可对话 + 显式多步推理 | 循环尚未产品化 |
| 接口 | 结构化工具调用、更长上下文 | 第一次能工程化地「想—做—看」 |
| 可验证 | 编码 / 多模态 / 长窗口 | 能打分的任务型 Agent |
| 内化 | 推理模型、原生 agentic | 运行时产品，协议开始统一 |
| 外溢 | 长程自主仍在涨，瓶颈外移 | 团队身份、沙箱、调度、审计 |

## 按年主线

每年一句话。点开年份页看切片、里程碑和「还做不到什么」。

- [2022 年之前](../before2022/)：前传。决策核还不是 LLM。
- [2022](../2022/)：底物就绪。可对话接口和思维链出现，Agent 循环尚未产品化。
- [2023](../2023/)：第一次工程化。ReAct 给出循环，Function Calling 给出接口，AutoGPT 点燃舆论，也把泡沫暴露出来。**从这一年读起最容易进入状态。**
- [2024](../2024/)：评测与协议。编码 Agent 成为可验证主战场；MCP 发布时并不热闹，后来才被追认为拐点。
- [2025](../2025/)：运行时产品。Agent 从开发库变成可直接用的运行时；协议层从 MCP 扩到 A2A。
- [2026](../2026/)：团队与基础设施。个体编码 Agent 之后，问题变成组织身份、共享工作区和执行路径。
- [2027](../2027/)：展望占位。现在是 2026，这里不写伪历史。

## 每年怎么读

年份页共用同一骨架，避免写成新闻汇编：

1. **一句话主线** — 读完能复述的那句
2. **和 LLM 的关系** — 模型这一年改写了哪些前提
3. **里程碑** — 按 [六类](./research/#里程碑类型) 标注：首证 / 工程化 / 标准 / 引爆 / 证伪 / 范式更替
4. **能力栈切片** — 模型 · 框架/协议 · 应用 · 基础设施，各写几条，不求全
5. **还做不到什么** — 防止写成胜利叙事
6. **怎么学 / 往哪跳** — 链到资料、产品、协议、基础设施的深挖页

读的时候同时看两种信号：**当时热度**和**后来是否站得住**。AutoGPT 的 star 数曾经远高于任何可靠 Agent；MCP 发布当年很多人没当回事。这两种错位本身就是历史。

## 建议的学习顺序

时间紧时走最短路径：

1. 本页（总弧线）
2. [调研方法](./research/)（边界和采信门槛，扫一遍即可）
3. [2023](../2023/)（循环、接口、泡沫）→ [2024](../2024/)（评测、MCP）→ [2025](../2025/)（运行时）→ [2026](../2026/)（团队与基础设施）
4. 需要渊源时补 [2022 年之前](../before2022/) 和 [2022](../2022/)
5. 往后盯线索用 [2027](../2027/) 提纲，不要当已经发生

最短路径过完，对「Agent 为什么在 LLM 之后才成为一类软件」会有完整骨架；其余深挖页按自己的工具栈插入。
