按时间线学习 AI Agent，是为了摸清 AI Agent 发展的脉络，不能简单的罗列信息。

定义：[什么是 AI Agent](/definition/what-is-ai-agent/)、[什么不是](/definition/what-is-not-ai-agent/)。四要素拆开读：[四要素视角](/definition/history/)。分类、标签、采信见 [调研方法](../research/)。年份页给脉络；论文 / 材料 / 讲解在里程碑子页，不在年表里复述原文。

每年都要回答一个核心问题：**该年决策核心多了什么能力，循环、动作、观察因此能实现什么，什么仍然做不到。** 语言模型年年进步；写进年份页的，只是改写了 Agent 执行语义的那些变化。

## 主脉络

AI 社区信息量太大，为避免噪音必须将关注点聚焦为 **LLM Agent**：核心决策下一步，循环迭代至终止，动作产生环境副作用，观察写回后再选。单轮问答、一次工具调用、行级补全排除。符号 / RL Agent 只作 [前传](../../before2022/)。

Agent 史 ≠ LLM 史。核心（指令、思维链、窗口、视觉、测试时计算）、循环（文本协议 → 编排类库 → 运行时）、动作（prompt 解析 → schema → 沙箱 / GUI / 工具总线）、观察（循环内回执 vs 仓库级谓词）四条不同步。

| 年份 | 阶段 | 核心提供的能力 | 系统据此能实现的特性 |
| ---| --- | --- | --- |
| 2022年之前 | 前传 | 还不能当开放文本上的策略 | 符号 / RL，只作渊源 |
| 2022 | 底层能力 | Transformer → 可对话 + 思维链 | 循环出现在论文里，产品未出现 |
| 2023 | 接口 | 结构化调用、稍长窗口 | 循环可工程化；完成率未证明 |
| 2024 | 可验证 | 编码、多模态、长窗口 | 有任务谓词；分数仍低 |
| 2025 | 内化 | 推理模型、运行时取代编排 | 日用编码 Agent；协议开始收束 |
| 2026 | 外溢 | 核心足够暴露系统问题 | 身份、沙箱生命周期、调度 |

## 按年组织

每年的发展总结为一句话。点开年份页看细节、里程碑和「还做不到什么」。

- [2022 年之前](../../before2022/)：决策核心不是 LLM。2017–2021 积蓄底层能力：上下文适应、可执行代码、受控浏览。符合 AI Agent 定义的系统远不存在。
- [2022](../../2022/)：指令契约、思维链、对话接口等底层能力就绪。ReAct 在协议层写出四条；ChatGPT 开始连接核心与聊天。结构化调用尚未出现。
- [2023](../../2023/)：循环被做成进程与产品。Function Calling 稳定解析；AutoGPT 形态接通、SWE-bench 谓词接近零。热度 ≠ 完成率。
- [2024](../../2024/)：仓库谓词成为默认尺子；Computer Use 打开 GUI 通道；MCP 发布时热度低，总线语义要到次年才被多家接上。
- [2025](../../2025/)：运行时内置循环（Claude Code、云端 Codex）。MCP 成为插槽；A2A / Skills 扩展边界与装载。框架与运行时必须分列。
- [2026](../../2026/)：个体循环日常之后，约束是主体（谁的权限）和供给（沙箱是否就绪）。写到 2026-09，不是全年盖棺。
- [2027](../../2027/)：梳理清晰发展脉搏和现状之后，才有资料谈展望未来。

## 年份页结构

1. **一句话主线** — 该年接通或暴露的那一层
2. **和 LLM 的关系** — 核改写了哪些执行前提
3. **里程碑** — 分类一、标签可多，也可无；发布会拆成当天真正改写执行语义的对象
4. **能力栈** — 模型 / 框架·协议 / 应用 / 基础设施。与单条分类不是同一轴
5. **仍不成立的配置** — 给后续年份当对照
6. **子页** — 论文、材料、讲解

两条信号并列：**当时热度**与**后来是否可核对**。AutoGPT 的 star 高于当时任何可交付系统；MCP 发布时无人当标准。错位本身是史实。

## 分类与标签

| 轴 | 问什么 | 取值 |
| --- | --- | --- |
| **分类** | 打开的是什么 | 论文 / 模型 / 产品 / 框架 / 协议 / 评测 / 文献 / 监管 |
| **标签** | 为什么进表 | 首证 / 工程化 / 标准 / 引爆 / 警示 / 范式更替 |

分类看打开的是什么，标签记的是历史角色，两者不是同一轴。GPT-4 是模型；ReAct 是论文（首证）；Function Calling 是协议（模型↔工具的方言），不是「又一只模型」；政府指令是 **监管**，不因为是厂商博客发的就归文献。细则与归类规则见 [调研方法](../research/)。前传八条经典概念同样给出分类与标签。
