## 当时解决了什么问题

ChatGPT 要人接着问。插件要人启用再聊。AutoGPT 把问题改成：能不能把 GPT-4 放进 `while` 循环，让它对着一个目标自己搜、自己写、自己再决定？这把 2022 年写在论文里的交错循环，做成了可 git clone 的脚本。

它没有新的训练方法，也没有新的工具协议。新的是**产品幻想的入口**：目标框，而不是对话框。

## 对后续 LLM 与 Agent 的影响

按 AI Agent 定义，这已经是 Agent：LLM 决策、多步循环、对环境行动、按回执再决策。2023 年几乎所有「自主 Agent」演示都沿这条幻想生长，也沿同一失败模式死去：计划漂、记忆靠窗口、解析失败、空转烧钱。10 月 SWE-bench 会把「修真实 issue」的分数打在接近零；那是对这类宣传的冷水，不是对「循环这个想法」的否定。

引爆型事件记热度；可靠性另记。两者不要合成一句「2023 年 Agent 已经能干活」。
