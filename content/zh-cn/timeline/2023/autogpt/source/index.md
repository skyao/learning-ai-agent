AutoGPT 没有对应一篇研究论文。本页转述 **2023 年 3 月公开爆红时仓库在说什么**，不以后来的产品品牌、云服务回填。

主要出处：GitHub `Significant-Gravitas/AutoGPT`（创建于 2023-03-16）；早期 README 与提示词将项目写成 *an experimental open-source attempt to make GPT-4 fully autonomous*。本页不复制仓库全文。

---

## 产品主张（当时）

给 Agent 一个用自然语言写的**目标**（以及角色/约束），由 GPT-4（或 GPT-3.5）在循环里自己决定下一步。早期演示里的动作包括：网页搜索、读写本地文件、执行代码、启动更多模型实例、把结果写入所谓长期记忆。人可以设一个总目标后少干预——这与 ChatGPT 一轮一轮确认不同。

循环的直观形状：思考当前状态 → 选择一个动作 → 执行 → 把观察写回上下文 → 再思考。格式直接抄自 ReAct 一类交错文本，外加任务列表与记忆。没有 Function Calling schema（接口要到 6 月）；解析靠模型吐出的结构化文本。

## 当时能看见的边界

仓库自称 **experimental**。公开讨论很快集中在：无限循环、重复同一失败、token 账单、以及在文件/网上做出难以撤销的操作。这些不是后来才发明的批评，是上线几周内就并排存在的反方意见。

它按循环和工具已经像 Agent；它没有提供可复核的任务完成率。热度指标是 GitHub star 与媒体标题，不是 SWE-bench 一类考卷——考卷要到 10 月才出现。
