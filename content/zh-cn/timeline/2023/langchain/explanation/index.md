## 当时解决了什么问题

ReAct 在论文里，AutoGPT 在一个大仓库里，RAG 在各人的 notebook 里。LangChain 提供一套共同名词：Agent、Tool、Memory、Chain。抄作业的成本从「读论文再手搓」变成「改一个工具类」。没有 Function Calling 之前，它用提示词解析撑过上半年；6 月之后又把函数调用收进同一套 Agent 抽象。

生日在 [2022 秋](../../../2022/langchain/)。2023 年记的是它成为教程和起步代码的默认层：当时必须有人把环跑起来。

## 对后续 LLM 与 Agent 的影响

工程化：2023 年大多数公开 Agent 教程从这里起步。警示：抽象层厚、版本不稳、出错时难以看见模型实际收到的提示——这些批评针对膨胀期，不能用来否定当年为何它先被用。当时生态与后来口味要分开看。

它是开发库，不是运行时：循环仍在你的服务器上，失败仍要自己停。控制流在库里，不在模型厂商。更薄的 SDK 和后来的代码优先运行时，是对这一层口味的修正，不是 2023 年已经发生的事。胶水可复制环；胶水不是协议，也不是完成谓词。
