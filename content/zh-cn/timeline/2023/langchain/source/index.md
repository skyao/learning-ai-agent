## 当时文档里的块

公开文档把 LLM 应用拆成可组合部件，名称在 2023 年稳定下来：

- **Model I/O：** 提示模板、聊天模型、输出解析。
- **Retrieval：** 文档加载、切分、向量库、检索器。这是 RAG 流水线的默认拼法。
- **Chains：** 把上列部件串成一步或多步调用。
- **Agents：** 由模型决定下一步调用哪个工具；`AgentExecutor` 跑思考—行动—观察循环，默认实现大量抄 ReAct 文本格式。
- **Memory：** 把对话摘要或检索结果再塞回提示。短期等于窗口，长期常等于向量库。
- **Tools：** 搜索、计算器、Python、HTTP 等包装，让 Agent 有可调用的函数。

开发者用 Python（随后有 JS）在自己的进程里托管循环。没有跨厂商协议：换模型厂商往往要换包装类。版本是 0.0.x，接口变动快，这是当时就存在的使用成本，不是后来才发明的抱怨。

## 公司与生态

2023-02 公司成立。2023 年融资与教程爆炸同步发生：ChatGPT 之后人人要「自己接工具」，现成胶水成为默认答案。LlamaIndex 等在检索侧分流，并不改变 LangChain 作为 Agent 入门词条的位置。
