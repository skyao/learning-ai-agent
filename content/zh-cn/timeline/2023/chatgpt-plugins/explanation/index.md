## 当时解决了什么问题

ChatGPT 能聊，不能查今天的网页，也不能订票。插件把「模型 + 外部 API」做成用户可开关的附件，不要求每个人自建循环。对普通用户，这是第一次看见对话框里出现「正在调用某某工具」。

调用嵌在一轮轮对话里，由用户接着问。它解决的是**可达的工具**，不是无人盯着的目标执行。清单、鉴权、manifest 仍是厂商私有协议。

## 对后续 LLM 与 Agent 的影响

厂商私有的工具清单（manifest / OpenAPI）成为 2023 年的默认做法。开发者侧三个月后的 Function Calling，把同类能力收进 API：从产品插件变成 schema。2024 年插件体系逐步关掉，能力拆进浏览、代码执行和后来的 GPTs Actions。

记它，是因为「终端用户 + 工具」这一产品形态从这里开始。不要写成已经稳定的开放协议，也不要写成 AutoGPT 那种无界环。按 AI Agent 定义，人在每一跳上点头，观察通道等于用户下一句——可达工具 ≠ Agent。
