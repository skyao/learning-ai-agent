本页转述 **2023 年 7 月对 ChatGPT Plus 全面放开时产品在说什么**，不以后来的 Assistants API Code Interpreter、改名 Advanced Data Analysis 回填材料细节。改名发生在约 9 月，属于同一功能的商标调整，不在本页展开。

主要出处：OpenAI 2023-07-06 公开滚动通知（全体 Plus 用户约一周内可用，需在设置中打开 beta）；ChatGPT 发布说明；插件期已把它列为官方插件的 alpha。本页不复制公告全文。

---

## 产品主张

模型在云端隔离环境里写并执行 Python，可选地读取用户上传的文件。当时公开列出的用途包括：分析数据、画图、编辑文件、做数学计算、在上传与下载之间转换格式。这与纯聊天不同：答案可以来自实际跑过的代码，而不是只生成一段看起来像代码的文本。

使用方式仍是 ChatGPT 对话。用户打开功能、上传文件、提问；模型决定写什么代码、在沙箱里执行、把打印结果和图表带回对话。人仍在循环里：下一步问什么由用户说。不是把一个开放目标交给系统自己转完。

沙箱有隔离边界：能跑的是环境里提供的 Python 与库，不能当作用户本机的任意 shell。会话级文件与有限的执行时间是当时使用体验的一部分。

## 当时不是什么

不是 11 月 Assistants API 里那个开发者可托管的同一工具接口——那是 DevDay 才把类似能力收给 API。也不是通用电脑操作：看不见屏幕，没有稳定的 GUI 动作。插件期的浏览是另一条线，本页只记代码执行。
