## 当时解决了什么问题

GPT-4 已经能写分析脚本，但写完没有地方安全地跑，结果也无法自动看图。插件 alpha 证明这条路走得通；7 月对 Plus 放开，使「上传表格、要一张图、要一个计算」变成数百万人能点的产品，而不只是开发者 notebook。

隔离是前提，不是附加项：一旦执行模型生成的代码，就必须限制文件系统、网络和持久化。这把环境问题从研究论文里的假设，变成产品默认架构。

## 对后续 LLM 与 Agent 的影响

工程化：沙箱开始成为 Agent 能力栈的基础设施层——后来 Assistants API、各种本地/云端代码工具都沿着「模型生成 → 隔离执行 → 回执进上下文」走。按 AI Agent 定义，对话里偶发的一次跑代码仍是人在循环的工具调用；循环和停机策略没有因此自动出现。但它把「环境」从抽象的 API 变成了真的进程。编码 Agent 要干活，先得有一个能失败、能看 traceback 的地方。
