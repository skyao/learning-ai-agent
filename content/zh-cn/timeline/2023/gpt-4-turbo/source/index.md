## 产品主张

预览中的下一代 GPT-4：更强、更便宜，上下文窗口 **128k**。知识截止到约 2023-04。同场还有平台上的多模态能力：带视觉的 GPT-4 Turbo。GPT-4 本身已在 7 月对 API 全面放开；这次是窗口、价格与工具组合的下一跳。

## 当时不是什么

不是新的 Agent 运行时，也不是 Function Calling 的替代。它是默认决策核心换档：一次请求能多装一些文件片段和对话。发布会里同时出现的 DALL·E 3 API、语音合成等，不进本条。
