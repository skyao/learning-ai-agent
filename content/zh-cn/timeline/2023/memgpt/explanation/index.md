## 论文解决了什么问题

2023 年 Agent 的长期记忆默认等于：窗口里塞得下的部分，外加一层向量库相似度搜索。窗口一满就摘要或丢掉；检索到的片段也不一定真的进当前提示。MemGPT 把问题改写成操作系统问题：主存有限，磁盘更大，缺页时自己发函数去取。Function Calling 在这里不是产品功能，是换页指令集。

## 对后续 LLM 与 Agent 的影响

首证：分层记忆可以成为 Agent 架构，而不只是 RAG 流水线的另一个 retriever。按 AI Agent 定义，这套系统在用工具（记忆函数）对环境（外部存储）行动，并按回执再决定——是记忆子系统上的 Agent 循环。延长的是环能走的步数和工作集可寻址范围，不引入新的动作类型。它还不是 ChatGPT 或各框架的产品默认；向量库外挂仍然是 2023 年底的主流拼法。

不要把后来的托管记忆产品写进这一页的材料。2023 年要记住的是诊断：上下文太短，截断和检索都不够，需要模型自己管理层级。能换页 ≠ 有完成谓词；工作集变大 ≠ 副作用自动正确。
