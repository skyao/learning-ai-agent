**一句话主线：** 2023 年，LLM Agent 在形态上第一次被工程化——ReAct 的文本循环被抄进产品，Function Calling 把工具从 prompt 约束收成 API，AutoGPT 把无界自主循环送上舆论顶点。同年也证明：热度不等于完成率。

2023 年是按时间线学 Agent 的样板页。定义和六类里程碑见 [调研方法](../../overview/research/)，总弧线见 [概述](../../overview/)。

## 和 LLM 的关系

没有 [2022](../../2022/overview/) 年底的对话接口和思维链，2023 的循环没有可挂载的核心。2023 年模型侧又补了两块落地前提：

- **更稳的多步决策核心。** [GPT-4](../gpt-4/)（2023-03）让「拆任务、选工具、读回执、再决定」在复杂指令上第一次达到可产品化阈值。前一年的 ChatGPT / GPT-3.5 已经能聊，长链工具使用仍然脆。GPT-4 是决策核心，不是 Agent；循环在宿主。
- **结构化的工具接口。** 上半年开发者仍在 prompt 里约束模型吐 JSON；[Function Calling](../function-calling/)（2023-06-13）把「选哪个函数、参数是什么」收进 Chat Completions API。这是**协议**：模型↔工具的第一种稳定方言。单次 Function Call 有一次 I/O，没有「根据返回值再选」。接口本身不是 Agent，却是后面所有编排的地基。
- **稍长一点的工作集。** 2023 年 `gpt-3.5-turbo-16k` 把窗口从约 4k 拉到 16k；11 月 [GPT-4 Turbo](../gpt-4-turbo/) 到 128k。上下文长度是一次轨迹能装下多少观察的物理上限——当时仍然偏短，长任务只能靠外部记忆和截断，状态丢失随处可见。窗口够，仍不产生副作用。

[Toolformer](../toolformer/)（2023-02）从训练侧证明「该在何时插入工具调用」可学，而不是只能靠提示词约定。[ReAct](../../2022/react/) 论文更早（arXiv 2022-10，会议在 ICLR 2023），但大规模抄进产品循环发生在 2023 上半年。叙事上：论文是首证，2023 年是它被抄成默认控制协议的一年。

## 里程碑

只记改写了后续可能的事件。每条一个**分类**，**标签**可多个（[六类历史角色](../../overview/research/#里程碑类型)）。ReAct 的论文在 [2022](../../2022/react/)，今年是被抄进产品的一年，不另占行。

| 时间 | 事件 | 分类 | 标签 | 为什么记 |
| --- | --- | --- | --- | --- |
| 2023-02 | [Toolformer](../toolformer/) | 论文 | 首证 | 从训练而非纯 prompt 证明「该在何时调工具」可写入权重，而不只存在于提示词约定 |
| 2023-03 | [GPT-4](../gpt-4/) | 模型 | — | 决策核心第一次撑得住稍长的工具链（schema、错误回执、部分结果之间保持目标）。后续产品默认站在它上面。核心不是 Agent |
| 2023-03 | [ChatGPT plugins](../chatgpt-plugins/) | 产品 | 工程化 | 把「模型 + 外部工具」做成面向终端用户的产品形态；清单与鉴权仍是厂商私有协议 |
| 2023-03 | [AutoGPT](../autogpt/) 爆红 | 产品 | 引爆 | 把终止条件交给模型自己写的任务队列，四要素在形态上接通。star 数度量传播，不度量完成率；空转与不可逆副作用是无界循环的预期行为 |
| 2023-03 | [BabyAGI](../babyagi/) | 产品 | 引爆 | 用更短的任务队列演示同一控制流归属：模型列任务、模型选下一步。衍生项目极多，大多很快消失 |
| 2023 全年 | [LangChain](../langchain/) 成为默认编排层 | 框架 | 警示 | 把 chain / agent / tool 做成库，循环可复制。后来的批评针对抽象层过厚，不否定「当时必须有人把循环跑起来」——当时生态与后来口味要分开看 |
| 2023-04 | [Generative Agents](../generative-agents/)（Stanford） | 论文 | 首证 | 用记忆流 + 反思做社会模拟，打开「长期记忆 / 角色」旁支。不是任务型 Agent 的主线：完成谓词是行为可信，不是仓库绿 |
| 2023-05 | [Voyager](../voyager/) 等「开世界」实验 | 论文 | 首证 | 在 Minecraft 等环境里展示终身学习式技能库；影响力在研究，不在生产 |
| 2023-06 | [OpenAI Function Calling](../function-calling/) | 协议 | 工程化 | 工具调用从 prompt 约束变成 API：name + arguments 可校验。循环仍由调用方写。后续各家 tool use 沿这条形状走。协议不是系统 |
| 2023-07 | [ChatGPT Code Interpreter](../code-interpreter/)（后称 Advanced Data Analysis） | 产品 | 工程化 | 模型在云端隔离 VM 里写代码、看图、处理文件。只要允许模型执行代码，沙箱就从可选项变成执行边界；观察通道是真实 stdout / 异常栈 |
| 2023-08 | [Microsoft AutoGen](../autogen/) | 框架 | 工程化 | 把多角色做成消息总线。控制流变成「谁对谁说话」。至少一方执行代码或外部调用，才有作用在环境上的循环；只产文本则仍是对话 |
| 2023-10 | [SWE-bench](../swe-bench/) | 评测 | 首证、警示 | 第一次给出仓库级完成判据：真实 GitHub issue 对应的测试必须通过。当时公开分数接近零。循环能转与目标已达成，从此必须分列 |
| 2023-10 | [MemGPT](../memgpt/) | 产品 | 首证 | 用操作系统式分层分页对抗窗口上限。延长的是循环能走的步数，不引入新动作类型 |
| 2023-11-06 | [GPT-4 Turbo](../gpt-4-turbo/) | 模型 | — | 128k 窗口，单次轨迹能多装文件。工作集变大 ≠ 副作用产生。发布会不当条目 |
| 2023-11-06 | [Assistants API](../assistants-api/) | 产品 | 工程化 | 线程、工具、检索收成托管状态机雏形。循环上云，锁在一家 API。GPTs 不单独升格 |

刻意不升格为里程碑的：无数「AutoGPT 克隆」、大多数行业演示、GPT Store 里的 GPTs（自定义助手，不是循环产品）、以及任何只有厂商通稿、没有可复现行为的「自主员工」宣布。发布会不当条目。

## 能力栈切片

### 模型层

GPT-4 让长链规划不再完全是幻觉；Function Calling 让工具选择可解析；16k–128k 上下文让单次循环能多装一点材料。推理仍是显式的：靠 CoT / ReAct 把想法写进文本，还没有后来的推理模型把规划藏进内部计算。多模态几乎还没进入 Agent 主线——看不见屏幕，就谈不上通用电脑操作。模型是核心，不是系统。

### 框架 / 协议层

2023 年的关键词是**框架，不是跨厂商协议**。

LangChain 提供 AgentExecutor、工具包装、记忆插槽，成为 2023 默认胶水。LlamaIndex 偏检索编排。AutoGen 把多 Agent 做成消息传递。它们都是开发库：调用方自己托管循环、自己接工具、自己处理失败。控制流在库里，不在模型厂商的运行时里。

工具协议是各家私有的：OpenAI plugins、Function Calling schema、各框架自己的 Tool 抽象。没有跨厂商的「模型 ↔ 工具」标准——那是 2024 年 MCP 的事。MCP 与 Function Calling 都是接线，不是 Agent。Assistants API 是托管运行时的雏形，仍锁在一家 API 里。

记忆方面，短期靠窗口，长期靠向量库外挂；MemGPT 指出这条路不够，提出分层分页，但还没有成为产品默认。

### 应用层

公众看见的是 AutoGPT 和 BabyAGI：给定目标，自己列任务、自己搜网、自己调 API。四要素形态接通；缺的是可靠解析、工作集管理、对「已完成」的外部检验。演示好看，真实完成率低。这是**引爆型**事件，不是可靠性事件。热度 ≠ 完成率。

稍扎实的应用形态其实更窄：检索增强的问答机器人、在沙箱里分析表格的 Code Interpreter、由人盯着的客服工具调用。Coding Agent 作为品类已经有人做（GPT-Engineer 等），但还经不起后来 SWE-bench 那种考核。浏览器 / 电脑操作仍属研究原型。

### 基础设施层

沙箱从「可选」变成「只要让模型跑代码就必须有」：Code Interpreter 是云端先例。评测刚刚摸到任务型 Agent——SWE-bench 在 10 月出现，WebArena 等网页基准也在 2023 年前后发表——观察通道进入产品，仓库级完成判据打到接近零。可观测性几乎空白：一次循环跑飞了，往往只剩日志和账单。

## 还做不到什么

2023 结束时，下面这些仍然不成立。把它们写清楚，是为了后面几年的进步有参照：

- **靠谱地做完一件几天级的事。** 循环会漂、会忘、会在同一失败上重复。自主度宣传远高于实际可放手程度。无界循环没有外部完成谓词，只能靠步数上限或账单熔断。
- **通用电脑操作。** 看不见屏幕，也没有稳定的 GUI 动作接口。
- **可验证的软件工程 Agent。** SWE-bench 给出了考卷，当时公开分数接近零。循环在第一层（观察写回）上转，在第二层（测试谓词）上失败。
- **跨产品的工具协议。** 每接一个模型厂商或框架，工具就要重写一遍。Function Calling 是一家方言，不是总线。
- **跨会话、可治理的记忆。** 向量库能搜到片段，不等于状态在任务之间可寻址、可审计。
- **组织级身份。** Agent 要么借用某个用户的 OAuth，要么拿一把泄露风险极高的 API key。动作的主体仍是用户。2026 年 Claude Tag 要解决的，正是这条线的后续。

当时就有反方意见：无限循环、prompt injection、成本、以及「给一个目标就去创业」类 demo 的空洞。这些批评对准的是控制流无界与副作用未隔离，后来被证明比 star 数更耐放。
