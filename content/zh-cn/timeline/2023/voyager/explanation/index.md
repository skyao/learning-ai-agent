## 论文解决了什么问题

Minecraft 没有固定通关剧本。先前 LLM agent 往往对着一个目标做一次 ReAct，做完就忘。这篇要的是：自己出题、做成了就存成函数、下次还能检索组合。动作空间选代码而不是原始按键，是因为程序天然表示一段延续的、可组合的行为。观察通道是库存与解释器报错，不是测试套件。

## 对后续 LLM 与 Agent 的影响

按 AI Agent 定义，这是具身环境里的 Agent：GPT-4 决策、多步写代码、看库存和报错、再改。它把 2023 年几条线接到一起——代码当工具、技能当外部记忆、课程当规划器。影响力在研究：后来「技能库 / 代码即策略」的开世界实验会引到这里。

它不是生产系统。控制依赖 Mineflayer 高级 API；评测在游戏里，不是 SWE-bench；token 成本高；自验证仍是另一只模型在看。完成谓词是游戏内进度，不是仓库绿。记首证：终身技能积累可以靠提示和库，不必先微调身体。不要记成「游戏 Agent 已经能当员工」。研究热度 ≠ 可部署完成率。
