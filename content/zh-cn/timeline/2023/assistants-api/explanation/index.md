## 当时解决了什么问题

2023 上半年，开发者要自己保存对话、自己解析函数调用、自己接检索、自己找地方跑代码。Assistants API 把这些收成「一个 assistant + 一个 thread + 一组工具」。同日的 [GPT-4 Turbo](../../gpt-4-turbo/) 用 128k 窗口让单次任务能多装一些文件片段。GPTs 把同一套能力做成不用写代码的定制聊天机器人，不单独记。

## 对后续 LLM 与 Agent 的影响

工程化：这是厂商托管运行时的雏形——循环不再必须发生在你的服务器上。对 AI Agent 定义而言，Assistants 可以跑多步工具调用（代码、检索、函数），因此**可以**构成弱自主 Agent；但产品默认仍是对话式助手，目标由用户一轮一轮给出。锁在一家 API 里：换模型厂商，线程和工具要重写。跨产品协议是下一年的 [MCP](../../../2024/mcp/)。

不要用后来的 API 迁移回填这一天。2023 年 11 月要记住的是：运行时开始被平台收走，可靠性并没有因此自动出现。
