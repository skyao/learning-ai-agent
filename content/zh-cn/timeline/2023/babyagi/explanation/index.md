## 当时解决了什么问题

AutoGPT 已经把循环摊在一个大仓库里。BabyAGI 把同一想法收成「队列 + 三个提示」：执行、生新任务、重排。读者能在一页纸上画出控制流。这降低了「自己做一个 Agent」的起步成本，也把失败模式暴露得更清楚——队列会自我膨胀，执行结果不一定推进目标。

## 对后续 LLM 与 Agent 的影响

按 AI Agent 定义，这也是 Agent，只是工具和环境往往薄到只剩 LLM 自己和一层向量库。后来许多多 Agent / 任务图框架，第一张示意图仍是「规划器往队列里塞任务」。它不是可靠运行时，也不是评测。记引爆：短脚本改变了 2023 年春天大家以为 Agent 长什么样；记限度：名字里的 AGI 是反讽，作者自己写过。
