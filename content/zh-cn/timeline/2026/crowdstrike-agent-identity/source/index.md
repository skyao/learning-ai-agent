## 三件事

**2026-08-31 — Falcon IQ / Project Quiltworks**：官方称用**超过 50 个 Agent** 自动化最耗时的安全工作流。

**2026-09-01 — Falcon Guardian（AI Agent 安全）**：官方原文写，传感器在 Windows 与 macOS 上**发现已知与影子 AI Agent**，给出每个运行中与休眠 Agent 的实时清单；定义**哪些 Agent 允许在受管终端上运行**，阻止未授权的，并「把治理策略翻译成可执行的运行时控制」。

**2026-09-02 — Agentic Identity Provider**：这是本批里最值得记的一条，官方给了三条规则：

1. 「**每个 Agent 被签发一个可加密验证的身份，不可冒用、不可共享。**」
2. 「**Agent 从不被授予它自己的常设凭证。** Agentic IdP 通过令牌代理访问，令牌按每个任务所需的**最小权限、最短时间**签发。」
3. 「**Agent 所做的每一个动作，都绑定到它所代表的那个人或那个工作负载。**」

**2026-09-02 — agentic SOC**：跨每个 Agent、每次调查、每个租户的**持久记忆**（「一个 Agent 学到的，它们都知道」）；客户可以为每个工作流设置**自治等级**，从人在环路批准到完全自主执行；支持双向 MCP。

## 口径提醒

官方文本自带「未发布服务」免责声明，部分能力仍写作「将提供」。写时间线时按「已公布的能力设计」记，不要写成已经全面可用。

## 与同类的关系

这套模型与[运行时侧](../../managed-agents/)的 scope bundle、[数据侧](../../snowflake-cortex-agents/)的跨应用授权是同一个方向的三种落地：**身份从「借用用户凭证」里拆出来**，动作绑定到委托人，凭证短时且最小。
