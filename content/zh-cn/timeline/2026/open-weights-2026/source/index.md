## 逐条

| 模型 | 日期 | 与 agent 相关的能力 |
| --- | --- | --- |
| **Qwen3.5**（阿里） | 2026-02-16 | 开源系列起点；年内迭代到 Qwen3.6 / 3.7 / **Qwen3.8**（8 月）。官方称 3.8 是「首次把 Qwen-Max 级模型开源」，强调长时程 agentic 任务、更强的自主规划与对环境的响应 |
| **MiniMax M2.5 / M3** | 02-12 / 06-01 | M3 的官方定位是「第一个也是唯一一个把三样凑齐的开源权重模型」：前沿编码 + **1M 上下文** + 原生多模态（可操作桌面） |
| **GLM-5.1 / 5.2 / 5.3**（智谱） | 04-07 / 06-16 / 08-18 | 5.2 的发布说明写「支持 1M 无损上下文，显著改善长时程任务能力，减少上下文漂移与目标遗忘」；5.1 称可单次独立工作约 8 小时 |
| **DeepSeek V4 / V4-Pro** | 04-24 开源预览 / 08-13 Pro GA | 官方写明「针对 agent 能力的专门优化」，点名与 Claude Code、OpenClaw、OpenCode 集成，并放出 **DeepSeek Harness**（agent harness 开发者预览）；1M 上下文为官方服务默认 |
| **Kimi K3**（月之暗面） | 07-16（权重 07-27） | 2.8T 总参 / 896 专家；**1M 上下文**；官方定位「为长时程编码、知识工作与深度推理构建」 |
| **Inkling**（Thinking Machines） | 07-15 | 975B 总参 / 41B 激活、1M 上下文、原生多模态。官方自我评价很克制：「Inkling 不是今天最强的模型，无论开源还是闭源」，定位是可定制的**开源基座** |

## 需要区分的一处

Kimi 的 **K2.7-code**（06-12）可在第三方模型索引中看到，但**没有找到对应的开源权重仓库**——「K2.7 开源」未能核实，本页不列为开源权重。

## 一句话总结这一年的变化

**1M 上下文、原生多模态、computer use、与主流 agent harness 兼容**——这四项在 2026 年从「旗舰闭源专属」变成「开源权重标配」。厂商自我定位也从「追平上一代」改成「面向 agent 工作负载设计」。
