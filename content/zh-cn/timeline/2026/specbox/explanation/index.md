## 论文解决了什么问题

Aries 测量到工具与沙箱不是边角。SpecBox 选其中一个可优化点：反应式「先说完再启动」把秒级冷启动串进每一步。MCP 把工具变成远程沙盒之后，这个问题更硬——协议标准化了调用，没有标准化「环境已经热着」。推测预热把意图从流式 token 里提前抠出来，让 CPU 侧准备和 GPU 侧生成重叠。

按 AI Agent 定义，SpecBox **不是** Agent，是给 Agent 服务的运行时调度。

## 对后续 LLM 与 Agent 的影响

产品上的短暂沙箱（用完释放）正好撞上冷启动。Tag 一类异步委派对尾延迟敏感：人 @ 完去开会，回来还在等环境。2.9× / 45.9% 是论文设置下的报告，不是可以写进所有 SLA 的常数。和 Aries 一起读：2026 年把执行基础设施写成主线，但「把沙箱调度问题做完」仍是研究与工程，不是已经换完的新底盘。
