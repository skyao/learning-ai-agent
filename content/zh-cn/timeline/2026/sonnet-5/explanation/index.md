## 当时解决了什么问题

2025 年能自主跑长程任务的模型都在最高档：价格决定了「敢于让 Agent 跑多久」。编码 Agent 的成本模型很直接——一次委派烧的 token 乘单价。单价不降，长任务就只能留给少数场景。

Sonnet 5 的公告没有讲新的能力类别，讲的是**同一类能力换到了中档价位**：会规划、会用浏览器与终端、能自主运行。配合 effort 维度的成本曲线，同等成本点上能覆盖此前 Opus 档的区间。

对做平台的人，这条的意义是**单位经济性**：同一笔预算能开的并发数、能容忍的重试次数、能放的沙箱存活时长，都由这个价格决定。

## 对后续 LLM 与 Agent 的影响

把它与 [Opus 5](../../opus-5/)（一个月后，同一条线的高档位）连起来读：2026 年年中，Anthropic 在高低两端同时推进自主能力——一端推上限，一端推价格。GPT-5.6 家族的 Sol / Terra / Luna 三档（[见下](../../gpt-5-6/)）是同一思路的另一家版本。

**决策核心的价格曲线开始决定 Agent 的产品形态**，这件事在 2026 年才变得明显。在此之前的叙事里，成本只是运维指标，不是能力边界。
