## 当时解决了什么问题

[Claude Code](../../../2025/claude-code/) 证明：终端里的多步循环能收工。大量人却拿它整理文件、做表、写稿——任务不是软件工程，工具却是开发者的。Cowork 去掉终端，把同一套「计划 → 动文件 → 看结果」接到桌面文件夹上。按 AI Agent 定义，这 **是** Agent：多步、对环境行动（文件系统与已连接工具）、按回执再决策。人在循环仍然在：重大动作要问，权限由用户划文件夹。

## 对后续 LLM 与 Agent 的影响

2026 年 1 月同时出现两条「Agent 住进日常」的表面，不要合成一种产品：

- [OpenClaw](../../openclaw/)：开源、自托管、从聊天软件指挥你的机器。热度高，暴露面也高。
- Cowork：厂商桌面应用、指定文件夹、付费档研究预览。循环同源 Claude Code，治理仍是「你的 Max 账号 + 你划的目录」。

半年后的 [Claude Tag](../../claude-tag/) 再换一层：共享频道、组织身份。Tag 博文自己拿 Cowork / Claude Code 当熟悉感参照——个人文件与本地仓库仍归这两条，频道协作归 Tag。读 2026 年，三条线并排：自托管个人、厂商个人知识工作、厂商团队工作区。模型可以共用，权限模型不能混写。
