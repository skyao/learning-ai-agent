## 2026-08-07：跨应用编排

Cortex Agents 与 MCP server 在 Snowflake 原生应用中一般可用。要点是**一个应用里的 agent 可以调用另一个应用里的 agent 或 MCP server**，而**每个应用保持自己的数据与逻辑私有**——「agent 只能通过提供方暴露、消费方批准的工具跨应用访问」。权限模型包含调用方授权、功能策略与角色委派。

## 2026-08-26：服务端执行 agent loop

编码 Agent 一般可用。官方原文写：「**Snowflake 执行工具并把结果流回你的应用，因此你不必自己构建或托管一个 agent loop**。」

## 2026-08-30：异步长任务

异步 API 一般可用。把请求的 `background` 字段设为真即可：**长任务在客户端断开后继续运行，超时上限 6 小时**。

## 三条合起来是什么

跨应用编排 + 服务端托管的环 + 断连可续的长任务——这三样此前都是开发者自己拼的：自己写编排、自己托管循环、自己做断线重连。这一轮把它们收进了平台。

## 需要更正的一条

流传的「Cortex Agents 于 2026-08-09 GA（跨库工具访问）」**是编造的日期**。Snowflake 官方 8 月的新闻稿只有另外两条，本条日期以官方发布说明为准。
