2026-01-15 发布，Apache-2.0。厂商中立的 **LLM API 规范**（客户端 ↔ 模型提供方），schema 源自 OpenAI 的一方 API。核心维护者来自 OpenAI、Databricks、Amazon、Hugging Face、Ollama、OpenRouter 等；治理条款写明**任何单一厂商不得占据多数核心维护者席位**，且所有治理角色由个人而非组织担任。

1. [材料](./source/) — 按仓库与规范转述：发起方证据、治理条款、规范内容、以及「不是 OpenAI 官方发布」这一区分。
2. [讲解](./explanation/) — 它是模型接口层，不是 Agent 通信层；与 MCP / A2A 不在同一层。

规范与仓库：[openresponses.org](https://openresponses.org)、[openresponses/openresponses](https://github.com/openresponses/openresponses)。
