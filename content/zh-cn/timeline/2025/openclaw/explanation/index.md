## 当时解决了什么问题

Claude Code 和 Codex 很强，但人要坐在 IDE 或 ChatGPT 前面。日常指令发生在手机聊天里；文件和浏览器在自己的电脑上。Clawdbot 把两边接起来：频道是表面，Gateway 在你控制的硬件上转循环。这是 **自托管个人 Agent**，不是 2025 年主线上「装一个官方 CLI」。按定义这 **是** Agent：多步、调工具、看回执。权限面等于机器本身；密钥、文件、shell 的风险从第一天绑在形态上。

## 对后续 LLM 与 Agent 的影响

2025-11 只是仓库出现。八周后的 [2026 年现象](../../../2026/openclaw/) 才把「养龙虾」做成大众事件，并带出暴露实例、恶意 skill、企业禁用。时间线必须把**出生**和**爆红**分开：否则会把 2026-01 的星标写进 2025-11。和 [Manus](../../manus/) 的差别：Manus 是云端托管的通用演示；龙虾是开源、自托管、频道入口。和 Claude Code 的差别：一个是开发者终端运行时，一个是从口袋里的聊天软件指挥你的电脑。principal 仍是机主账号，不是组织级 Agent Identity。
