Anthropic，2025-12-18。10 月发布的 Agent Skills 格式（目录 + `SKILL.md` + 三级渐进披露）转成跨平台开放标准，规范与客户端登记表独立到 agentskills.io，仓库 Apache-2.0。公告称格式由 Anthropic 最初开发、已作为开放标准发布，并被越来越多的 Agent 产品采纳。

1. [材料](./source/) — 按当时规范与公告转述：格式约束、加载三阶段、采纳名单。
2. [讲解](./explanation/) — 标准管的是能力包的可移植性，不管执行；与 [2025-10 的原始发布](../agent-skills/) 是同一格式的两步。

规范：[agentskills.io/specification](https://agentskills.io/specification)。仓库：[agentskills/agentskills](https://github.com/agentskills/agentskills)。
