## 当时解决了什么问题

2024-10 [Computer Use](../../../2024/computer-use/) 是开发者 API：调用方自备桌面。Operator 把同一条动作通道做成可打开的站点——Agent 自带浏览器，不必先搭 VM。CUA 把「看 + 点」训成专用核；视觉输入是前提，点击策略是另一层。

按定义这 **是** Agent：核选动作，副作用在远程 GUI，观察是新截屏。人下任务、对敏感步确认。登录墙、验证码、复杂后台仍脆；能点 ≠ 完成谓词已通。

## 对后续 LLM 与 Agent 的影响

7 月并入 [ChatGPT agent](../../chatgpt-agent/)：浏览执行不再是另开产品，而是聊天入口里的一种模式。电脑/浏览器线的成功率明显低于编码运行时。没有这条预览，看屏仍停在 2024 的 API 与 OSWorld 低分。两条可靠度曲线不要并成一句「已经会用电脑」。
