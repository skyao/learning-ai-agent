## 当时解决了什么问题

Claude Code / Operator 都偏专线：编码，或浏览器。Manus 用「通用助手在云电脑里干活」把 2023 年 AutoGPT 的幻想重新做成 2025 年的消费演示：行程、研报、建站，一条视频打穿。邀请制制造稀缺，热度来得比评测快。

按 AI Agent 定义，演示中的系统 **是** Agent：多步、有环境、有反馈。自主度宣传很高；可复现的可靠度当时跟不上宣传。

## 对后续 LLM 与 Agent 的影响

通用云端 Agent 成为中文舆论里的品类名，和编码运行时、研究按钮并列。后来的跟风产品很多。记法与 AutoGPT 相同：引爆要上表，不要把首发周的 GAIA 自报当成行业水位。人在循环的专线产品（编码、研究）在 2025 年把日常使用做实；通用线继续吃「什么都能干」的期望税。
