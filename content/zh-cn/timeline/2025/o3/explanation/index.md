## 当时解决了什么问题

[o1](../../../2024/o1/) 把长思考藏进模型，但工具仍多半在思考结束之后由宿主另调。o3 把浏览、代码、看图收进思维链：模型可以边想边查、边算、边看图。对 Agent 搭建者，这意味着「规划 / 试错」不必全写在 ReAct 明文里，一部分由推理核在内部完成。代价仍是延迟和账单；effort 档是把这笔账暴露给开发者。

按 AI Agent 定义，**o3 本身不是 Agent**。它是更会用工具的决策核心。循环、沙箱、停机，仍在 Claude Code / Codex / 自建 SDK 一侧。

## 对后续 LLM 与 Agent 的影响

没有 4 月这只核，5 月的 [Codex](../../openai-codex/) 不会有 codex-1（o3 的软件工程变体），Deep Research 的长检索也不会挂在同一条推理线上。8 月 [GPT-5](../../gpt-5/) 把「快答 + 思考 + 路由」收成默认系统，o 系列作为独立模型选择器开始退场。记法与 o1 相同：换核，不换品类。
