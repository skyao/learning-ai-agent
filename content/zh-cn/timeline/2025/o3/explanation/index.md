## 当时解决了什么问题

[o1](../../../2024/o1/) 把长思考藏进模型，工具多半在思考结束之后由宿主另调。o3 把浏览、代码、看图收进思维链：决策与「该不该调用」并进，不必每一步在明文 ReAct 里写完规划。effort 档把延迟和账单暴露给调用方。

按定义 **o3 不是 Agent**。思维链里的 tool 标记仍是意图；Python、HTTP、文件系统的副作用发生在运行时一侧。没有 Claude Code / Codex / SDK 的循环，它只是一次（或一段）更会选工具的补全。

## 对后续 LLM 与 Agent 的影响

没有这只核，5 月 [Codex](../../openai-codex/) 的 codex-1（o3 的软件工程变体）和 Deep Research 的长检索都缺少默认引擎。[GPT-5](../../gpt-5/) 再把快答 / 思考 / 路由收成系统，o 系列作为独立选择器退场。记法与 o1 相同：换核，不换品类。把内部 CoT 当成已经实现作用在环境上的循环，会漏掉宿主。
