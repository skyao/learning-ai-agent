## 产品主张

Codex 是**云端软件工程 agent**：可并行处理许多任务。能写功能、回答代码库问题、修 bug、提出供人审的 PR。**每个任务**跑在自己的云沙箱里，预装你的仓库；可读改文件、跑命令、测试、linter、类型检查。任务常见耗时约 1–30 分钟，可监视进度。

引擎：**codex-1**，OpenAI o3 面向软件工程的变体。用真实编码任务上的强化学习训练，目标包括贴近人的代码风格与 PR 偏好、精确遵从指令、迭代跑测试直到通过。

可用性：当天起滚动给 ChatGPT **Pro、Enterprise、Business**；Plus / Edu 随后。最初数周较宽松的用量，之后限额与加购。同日更新开源 **Codex CLI**（终端里的编码 agent），默认改用面向软件工程的 o4-mini 变体，并在 API 计价。

## 当时不是什么

**不是** 2021 年那个把自然语言补全到代码的 Codex 模型。不是本地 IDE 插件本身（CLI 是另一表面）。研究预览：虚拟队友、做完「数小时到数天」的工程，是内部愿望与 briefing 里的方向，不是当天已验证的普遍交付。
