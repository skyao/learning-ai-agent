## 当时解决了什么问题

Claude Code 与 Codex 证明运行时可以当产品卖。编辑器厂商不能只停在补全：用户已经会问「能不能让它自己改完这几个文件」。2025 年中把长循环放进已经打开的窗口，减少「另开一个网站/云控制台」的切换。人在循环：随时打断、审 diff，失败成本仍低于把钥匙交给全自主云工人。

按 AI Agent 定义，这些模式 **是** Agent（多步、改环境、看测试/编译反馈）。自主度通常低于 Devin 叙事，高于 2024 年的 Tab。

## 对后续 LLM 与 Agent 的影响

开发者日常被这层习惯锁住。2026 年要解决的不是「会不会在 IDE 里改代码」，而是团队频道里那一个身份。专线编码的可靠度继续高于通用电脑操作和研究型长稿。
