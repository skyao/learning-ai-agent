## 当时解决了什么问题

Operator 单独一个域名，教育成本高：用户不知道该去 ChatGPT 还是去 Operator。并入之后，「让它去网上干活」和「让它做深度研究」变成同一产品里的模式选择。这是包装，也是能力叠：视觉浏览器可以喂给研究循环。

按 AI Agent 定义，agent mode **是** Agent。人在 ChatGPT 里委派。

## 对后续 LLM 与 Agent 的影响

OpenAI 消费入口统一成「聊天 + 可选长循环」。Anthropic 走的是 Claude Code / 后来 Tag 的工作区路线，不是同一个表面。可靠度排序没有因为并入口而翻转：编码运行时仍更扎实，点网页仍更脆。
