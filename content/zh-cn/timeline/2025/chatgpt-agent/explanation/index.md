## 当时解决了什么问题

[Operator](../../operator/) 单独一个域名，教育成本高：用户不知道该去 ChatGPT 还是去 Operator。[Deep Research](../../deep-research/) 已是聊天里的模式。并入之后，「让它去网上干活」和「让它做深度研究」变成同一产品里的开关。这是包装，也是能力叠：视觉浏览器可以喂给研究循环。

按定义 agent mode **是** Agent。人在 ChatGPT 里委派。并入口没有把 GUI 线的完成谓词抬到编码运行时的水平。

## 对后续 LLM 与 Agent 的影响

OpenAI 消费入口统一成「聊天 + 可选长循环」。Anthropic 走 Claude Code / 后来 Tag 的工作区路线，不是同一个表面。可靠度排序没有因为并入口而翻转：编码运行时仍更扎实，点网页仍更脆。读 2025 年中，这一条是产品边界事件，不是新的执行语义。
