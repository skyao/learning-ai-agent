本页转述 **2025 年春季跨厂商支持当时公开说了什么**。规范内容见 [2024 MCP 材料](../../../2024/mcp/source/)，此处不重复。

主要出处：OpenAI CEO 2025-03-26 公开说明——MCP 当日可用于 Agents SDK，ChatGPT 桌面与 Responses API「即将」；随后 Responses API 博文宣布支持远程 MCP server，并称加入 MCP 指导委员会。Google 等在 4 月 A2A 公告里把 MCP 写成接工具的既有标准。本页不复制推文或博文全文。

---

## 当时主张

Anthropic 在 2024-11 开源的 MCP，被写成「人们喜欢」，OpenAI 要在**自家产品里加上支持**——包括桌面 ChatGPT。这是对手协议被采纳，不是 OpenAI 另发一套连接器标准。

落地是分阶段的：先 SDK，后桌面与 API 远程 server。生态侧已有一批 MCP server（支付、电商、客服工具等被后来的 API 博文举例）。Google 在 A2A 发布里明确：MCP 管工具与数据，A2A 管 agent 互操作。

## 当时不是什么

不是 2024 年 11 月「其实已经统一」的补记。2025 年春季才出现足够多的**第二家、第三家**大模型厂商背书。也不是所有产品默认插上 MCP；授权、远程 vs 本地、OAuth 细节仍在演进。
