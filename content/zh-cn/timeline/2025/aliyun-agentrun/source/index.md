## 当时说了什么

- **定位**：函数计算推出的「一站式 Agentic AI 基础设施平台」，以**高代码为核心**，覆盖 Agent 应用的开发、部署、运维全生命周期；可集成 AgentScope、LangChain、ADK、CrewAI 等框架，支持云端托管或私有化部署。
- **弹性与计费**：宣称从 0 到百万级并发弹性、精细化计费。
- **休眠与唤醒**：通过请求感知调度、实例冻结与内存快照，实现**运行时与沙箱的自动休眠**和**毫秒级唤醒**（厂商自报 1 毫秒）。
- **会话亲和**：公告明确写「**突破传统 Serverless 的无状态限制**」，为 Agent 提供运行时状态的持久化与上下文管理，保障多轮对话。
- **内置沙箱**：Code Interpreter、Browser Tool、All In One 等，内置多语言执行引擎与浏览器自动化引擎，面向多租户提供隔离。
- **治理与追踪**：模型侧用统一代理屏蔽 API 差异；工具侧用 MCP 标准化封装、Hook 与智能路由；全链路追踪把每一步决策路径、耗时与状态可视化。

## 当时不是什么

这不是模型或协议事件，也不提供新的 Agent 循环语义——循环仍由框架或调用方决定。它回答的是**执行位置**问题：Agent 的运行时和沙箱在云上以什么形态存在、按什么计费、状态怎么跨请求活着。

「毫秒级唤醒」「降低多少 TCO」这类数字都是**厂商自报**，公告没有给出可复现的测量口径。写进时间线时按当时主张记，不作独立结论。
