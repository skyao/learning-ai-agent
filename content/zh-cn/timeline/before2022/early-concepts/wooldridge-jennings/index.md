原文：[Wooldridge & Jennings, 1995](https://www.cs.ox.ac.uk/people/michael.wooldridge/pubs/ker95.pdf)，*Intelligent Agents: Theory and Practice*，*The Knowledge Engineering Review* 10(2): 115–152。[DOI](https://doi.org/10.1017/S0269888900008122)。这是一篇面向当时研究社区的长综述，不是新模型论文。作者在摘要中写明：目的是标出设计与构造智能体时最重要的理论与实践问题，并指向展开这些问题的工作；不打算写成对所有议题的教程。

## 这个概念是什么

到 1995 年，「Agent」已经同时出现在人工智能与主流计算机科学里，但用法不统一。这篇综述做了两件对后来教学影响很大的事：

1. 把议题分成三块——**Agent 理论**、**Agent 架构**、**Agent 语言**——即使分界有时任意，也足以把「是什么」「做成什么结构」「用什么语言写」分开讨论。
2. 给出两套沿用至今的定义口径：**弱概念**（来自计算机科学一侧的四个属性）与**强概念**（再叠加上知识、信念、意图等心智谓词）。

它不提供一个可运行的规划器或通信栈，而是提供一张 1990 年代中期的问题地图。后面读 [STRIPS](../strips/)、[BDI](../bdi/)、[包容架构](../subsumption/)、[FIPA](../fipa-acl/) 时，可以用这张地图给材料定位。

## 论文的主要内容

### 弱概念：四个属性

作者从计算机科学文献中归纳出，若称一个硬件或软件系统为 Agent，通常至少要求：

| 属性 | 论文中的含义 |
| --- | --- |
| 自主（autonomy） | 无需他人持续直接干预即可运行；对自己的行为和内部状态有控制 |
| 社交能力（social ability） | 通过某种 Agent 通信语言与其他 Agent（以及可能的人类）交互 |
| 反应性（reactivity） | 感知环境，并在环境变化时及时作出响应 |
| 主动性（pro-activeness） | 不只被动响应，还能采取目标导向的主动行为 |

这四条后来被大量教材与产品文档转述。论文自己的限度：这是对当时用法的归纳，不是一组已经配备操作化度量的测试。恒温器勉强可以装进「感知并响应」；社交能力与主动性则把许多脚本系统排除在外，但仍比 AI Agent 定义宽。弱四条已经假定感知与行动；它们不指定决策核心是什么。

### 强概念：心智谓词

在 AI 研究中，Agent 还常被赋予人类才使用的心智描述：知识、信念、意图、义务等。作者称之为强概念。这一侧与 [BDI](../bdi/) 直接相接：不是「系统会不会动」，而是「用哪些内部态度解释和设计它的选择」。

弱概念与强概念不是互斥的两代产品，而是两套描述粒度。一个 BDI 系统通常被期望同时满足弱四条，再用信念—目标—意图去说明它如何满足。

### 三块议题

**理论**处理「Agent 是什么」以及用何种数学形式表示和推理其性质。内容包括：如何形式化信念与目标、意图与承诺、Agent 之间的义务与规范、合作与冲突。Cohen & Levesque、Rao & Georgeff 的工作落在这一块。理论工作的目标是可陈述的性质，不等于已经得到可高效执行的程序。

**架构**是满足理论性质的软件或硬件组织方式。综述把当时架构分成三类：

1. **慎思式（deliberative / symbolic）**：内部有符号世界模型，决策通过规划、定理证明等符号操作完成。STRIPS 式规划器属于这一端。限度是：表征是否赶得上环境变化（calculemus 问题）、符号接地。
2. **反应式（reactive）**：决策主要由当前感知到的情境触发，不经过（或不依赖）完整中央模型。[Brooks 包容架构](../subsumption/) 是这一端的代表。限度是：如何处理需要长时间跨度信息的任务、如何从局部行为得到可预测的全局目标达成。
3. **混合式（hybrid）**：常见做法是分层，一层反应、一层慎思，用中间层协调。分层本身不能自动解决层间接口问题。

**语言**指用于编程和实验 Agent 的软件系统。文中评述的包括 Agent0、PLACA、Concurrent MetateM 等：重点是语言把哪些理论概念变成可写的原语（承诺、消息、并发规则），而不是给出通用运行时。

文章后部用当时的应用（工作流、电信、空管、信息管理等）说明：工业兴趣已经出现，但可移植的工具链仍弱。这一判断与一年后 [FIPA](../fipa-acl/) 开始写互操作标准的动机是同一背景。

### 作者标明的限度

摘要与导言反复说明：分三块是为了方便，分界并不干净。综述指向文献，不代替任何一篇原论文。弱四条是用法归纳，用来帮助读者辨认讨论对象，不是形式化定义。

## 关键术语

| 术语 | 在这篇论文里的含义 |
| --- | --- |
| 弱概念 | 自主、社交、反应、主动四属性 |
| 强概念 | 在弱概念之上使用心智谓词 |
| Agent 理论 | 用形式系统陈述 Agent 的性质 |
| Agent 架构 | 慎思 / 反应 / 混合等软件或硬件组织 |
| Agent 语言 | 把理论概念写成可编程原语的系统 |

## 和 AI Agent 的关系

**它把 Agent 研究分为理论、架构、语言三块，给出弱四条口径。它是分类，不是实现；本站定义再加约束。**

本站的栏目分工与这三块对应，但对象已经收窄为 LLM Agent：定义页对应「是什么」；时间线对应性质何时变得可工程化；协议栏对应社交能力这一条如何被写成 MCP / A2A；Agents 与基础设施对应架构与运行时。Wooldridge 与 Jennings 没有讨论语言模型。

弱四条已经覆盖循环、动作、观察中的若干条（反应、主动、社交）。AI Agent 定义是在弱/强概念之后再增加约束：决策核心必须是 LLM，并且具备多步循环、对环境行动、按反馈迭代。弱四条单独使用时，仍会把大量非 LLM 系统算进来。这一页用来理解 1995 年社区内部的分类，而不是替换工作定义，也不是 2022–2025 运行时的设计说明书。
