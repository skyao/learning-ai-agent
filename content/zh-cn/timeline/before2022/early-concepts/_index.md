大语言模型出现之前，Agent 已有完整的研究传统。这一栏交代概念库存：世界怎么写、任务怎么分、控制怎么切、心智状态怎么形式化、异构节点怎么通信、消费级助手实际跑的是哪条流水线。

这些系统**可以**具备循环、对环境的动作，以及观察写回。缺少的是工作定义的第一条：下一步由 LLM 选择。与 AI Agent 的对照放在各页后部，不代替对机制本身的说明。它们不是 2022 至 2025 年产品的祖先。

## 学习内容

按时间顺序，八个节点覆盖四类问题：

| 时间 | 概念 | 要搞清楚的问题 |
| --- | --- | --- |
| 1971 | [STRIPS](./strips/) | 经典规划里，世界、动作、计划分别是什么 |
| 1980 | [Contract Net](./contract-net/) | 多个求解节点如何用协商分配任务 |
| 1986 | [Brooks 包容架构](./subsumption/) | 不建立完整世界模型的控制结构如何工作 |
| 1991 | [BDI](./bdi/) | 信念、愿望、意图在形式化里各指什么 |
| 1995 | [Wooldridge & Jennings](./wooldridge-jennings/) | 1990 年代如何给 Agent 下定义、如何分类架构 |
| 1995 | [Russell & Norvig](./russell-norvig/) | 教材里的理性 Agent 覆盖到多宽 |
| 1996 起 | [FIPA 与 ACL](./fipa-acl/) | Agent 通信标准规定了哪些消息与平台组件 |
| 2011–2014 | [Siri / Alexa / 任务型对话](./task-oriented-dialogue/) | 大规模语音助手的流水线实际是什么 |

## 组织方式

每页固定三块：

1. **这个概念是什么**：不预设 LLM 背景，先给定义。
2. **论文或材料的主要内容**：问题、机制、例子，以及作者自己给出的限度。
3. **关键术语**：后面年份还会遇到的词，先在原文语境里明确。

与 AI Agent 的对照放在各页后部。循环可以早已存在；决策核心是换核心，不是同一条产品线的延续。
