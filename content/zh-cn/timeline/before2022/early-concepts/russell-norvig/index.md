材料：Stuart Russell & Peter Norvig，*Artificial Intelligence: A Modern Approach*，第 1 版，Prentice Hall，1995。这是教科书，不是会议论文。对 Agent 的集中表述在第 2 章 *Intelligent Agents*。后续版本（2003、2010、2020）在同一框架上补充了环境性质的分类表，以及用 PEAS（Performance, Environment, Actuators, Sensors）组织设计问题的写法。下面以第 1 版的定义为主，不把后版才固定的口号倒填为 1995 年原文。

## 这个概念是什么

AIMA 把人工智能的研究对象统一写成 **Agent**：任何可以被视为通过传感器感知环境、并通过执行器（第 1 版用 effectors）作用于环境的东西。Agent 的行为对错，不按「是否像人」来判，而按给定**性能度量**在该环境中的表现来判。在这个标准下，恒温器、棋手、诊断程序、机器人都是 Agent。

这套定义的目的是给整本教材一条脊梁：搜索、逻辑、规划、学习都可以写成「如何构造更合理的 Agent 程序」。它不是 2023 年以后那种软件产品分类，也不区分决策核心是规则、搜索、强化学习还是语言模型。

本站后来使用的「LLM Agent」是对这套定义的**收窄**，不是对它的否定。收窄的理由写在 [什么不是 AI Agent](/definition/what-is-not-ai-agent/)。

## 材料的主要内容（第 2 章框架）

### Agent 与环境

教科书给出的基本图是闭合回路：环境产生可被感知的刺激，Agent 经传感器得到**感知**（percept），输出**行动**，行动改变环境，下一时刻的感知依赖于环境的新状态。完整的输入历史称为感知序列。

作者区分两个层面：

- **Agent 函数**：从感知序列到行动的数学映射，描述理想行为。
- **Agent 程序**：在某种架构上实现该映射的具体程序。教材关心的是如何设计程序，使其在目标环境中逼近合理的 Agent 函数。

### 理性

**理性 Agent** 的标准（第 1 版的表述，后续版本沿用同一思想）是：对每一个可能的感知序列，理性 Agent 应选择这样一个行动——在该感知序列所提供的证据、以及 Agent 所具有的先验知识之下，期望最大化其性能度量。

几条经常被误读、需要按教材原意明确的推论：

- 理性不等于全知。Agent 无法根据未感知到的信息行动。
- 理性不等于事后正确。在不确定环境中，按期望最优仍可能得到坏结果。
- 理性允许（在有益时）收集信息，也允许学习；「一开始知识很少」并不自动非理性。
- 性能度量由设计者在 Agent 之外给定，不是 Agent 自己宣布「我成功了」就算数。

### 环境与 Agent 程序的类型

第 1 版已经按可观测性、确定性、情节性、动态性、连续或离散等维度讨论环境，并据此说明哪种程序结构够用。后续版本把这些维度列成表，便于出题；内容没有离开第 2 章的原意。常见的程序类型包括：

| 类型 | 决策依据 |
| --- | --- |
| 简单反射 | 当前感知与规则（条件—行动） |
| 带内部状态的反射 | 当前感知 + 对未观测世界的内部估计 |
| 目标驱动 | 内部模型 + 目标，需搜索或规划 |
| 效用驱动 | 在多个可达目标之间用效用函数比较 |
| 学习型 | 以上任一结构，加上从经验改进组件的机制 |

[STRIPS](../strips/) 属于目标驱动这一档的经典规划实现。[BDI](../bdi/) 在教材分类里仍是目标驱动，但内部状态被写成三种态度。[包容架构](../subsumption/) 更接近多层反射，而不是先搜出计划。[任务型对话](../task-oriented-dialogue/) 的状态机填槽，是反射加内部对话状态，目标集合通常封闭。

后续版本中的 **PEAS** 把设计一个 Agent 时必须同时交代的四件事写成检查清单：性能度量、环境、执行器、传感器。第 1 版已经要求这四件事一起谈；PEAS 只是后来的命名。整理笔记时可以用这个清单检查描述是否完整，但应标明它是后续版本的整理。

### 这一定义有多宽

因为判定标准只含感知、行动、环境、性能，所以：

- 恒温器是 Agent：感知温度，行动是开关加热器，性能可以是温度偏差。
- 国际象棋程序是 Agent：感知棋盘，行动是合法走子，性能是胜负。
- Siri 一类助手是 Agent：感知语音，行动是调用厂商 API，性能可以是任务完成率。

教材需要这个宽度，才能把人工智能各分支写进同一章。本站若沿用这个宽度，「AI Agent 时间线」会变成人工智能通史，与 [调研方法](../../../overview/research/) 的边界冲突。

## 关键术语

| 术语 | 在这本教材里的含义 |
| --- | --- |
| Agent | 通过传感器感知环境、通过执行器行动的任何东西 |
| 感知序列 | Agent 迄今收到的全部感知 |
| Agent 函数 / 程序 | 理想映射与具体实现 |
| 理性 | 在每个感知序列上选择期望最大化性能度量的行动 |
| 性能度量 | 在 Agent 外部给定的评价标准 |
| 环境性质 | 可观测、确定、情节、动态、离散等，用来选程序结构 |

## 和 AI Agent 的关系

**教材用理性 Agent 统摄 AI：感知、行动、环境、性能度量。有循环和动作，但核心不限 LLM，本站收窄了这一条。**

教材四元组里，循环、动作、观察已经画在第 2 章的图上。收窄发生在决策核心与迭代条款：

| 教材 | 本站的工作定义 |
| --- | --- |
| 感知 | 保留，具体化为工具回执、屏幕、仓库等观察 |
| 行动 | 保留，且必须改变环境，不能只生成文本 |
| 环境 | 保留，主线限制在软件环境 |
| 性能度量 | 保留，要求可核对的评测或交付，不以厂商自称代替 |
| （不限制决策核心） | **必须由 LLM 选择下一步** |
| （不强制多步迭代） | **必须有多步循环，并依据反馈再决策** |

因此 Siri 在 AIMA 中是 Agent，在本站的工作定义中降为助手。Wooldridge & Jennings 的弱四条是研究社区内部的入口，仍宽于本站的工作定义，但已经比恒温器窄（要求社交与主动）。AIMA 是课程与大众读物的入口，是「人人会说 Agent」的主要来源。它不是 2022–2025 LLM Agent 产品的规格书。
