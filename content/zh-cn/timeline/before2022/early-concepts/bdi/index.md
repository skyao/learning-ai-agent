形式化原文：[Rao & Georgeff, 1991](https://www.ai.rug.nl/mas/documents/rao.pdf)，*Modeling Rational Agents within a BDI-Architecture*，KR 1991，pp. 473–484。实现向的配套报告：Rao & Georgeff, 1995，*BDI Agents: From Theory to Practice*（ICMAS）。哲学来源：Michael Bratman, *Intention, Plans, and Practical Reason*（1987）。对照对象：Cohen & Levesque, 1990，把意图定义成信念与目标的时序公式。

## 这个概念是什么

BDI 指一类把 Agent 的内部状态分成三种态度的架构：

- **Belief（信念）**：Agent 认为世界处于何种状态；可以为假，需要随观察修正。
- **Desire / Goal（愿望 / 目标）**：Agent 希望达成的状态。论文把**目标**收窄为已选定、且内部一致的愿望，并且 Agent 必须相信该目标是可达成的。
- **Intention（意图）**：Agent 已承诺去尝试实现的那些行动方案。意图是部分的行动计划，对后续推理有约束，不能还原为「信念加上愿望」。

Bratman 的论题是：意图在实践推理中有独立作用——它是尚未完成的部分计划，会控制行为、排除与之冲突的其他选项，并且具有惯性（不会每一步都从头权衡）。Rao 与 Georgeff 把这一论题写成可能世界语义，使意图与信念、目标平级，从而可以讨论不同的**承诺策略**（intention 在什么条件下被保持或放弃）。

按本笔记工作定义，BDI 系统的决策核心是符号结构与规则，不是语言模型，因此不是 LLM Agent。它属于 1990 年代智能体文献中的 Agent。

## 论文的主要内容（1991）

### 要解决的问题

已有形式化（尤其 Cohen & Levesque）把意图写成信念与目标的某种时序组合，例如：对意图狂热承诺的 Agent 会维持目标，直到相信目标已达成或不可达成。Rao 与 Georgeff 认为这样无法把意图当作一等对象，也难以对意图本身施加与目标不同的持续性条件。他们要给出另一种可能世界形式化，使：

1. 意图与信念、目标平级，不能化约；
2. 区分 Agent **可选择**的行动分支，与行动执行后由环境决定的结果；
3. 信念、目标、意图之间有兼容关系，以避免可能世界框架里常见的「连不愿接受的副作用也一并承诺」的问题。

### 时间树与模态

世界被建成**时间树**：未来分支、过去唯一。某一世界中的某一时间点称为一个情景（situation）。事件类型把时间点变成另一时间点。原子事件由 Agent 直接执行，并唯一决定下一时间点；非原子事件对应不相邻时间点，用来表示部分计划及其向原子事件的分解（层次规划）。

从某一时间点伸出的分支表示 Agent 当时可做的选择。执行可能成功或失败，分支按此标记，从而 Agent 可以对意图采取行动，而不被要求每次尝试都成功。

逻辑是分支时间逻辑 CTL\* 的一阶、多模态扩充。公式分状态公式（在某一时间点求值）与路径公式（沿某一路径求值）。`optional φ` 表示从该点出发至少有一条路径使 φ 成立；`inevitable φ` 表示所有路径皆然。再加上 next / eventually / always / until。`BEL(φ)`、`GOAL(φ)`、`INTEND(φ)` 都是状态公式。事件方面有 `succeeds(e)`、`fails(e)`、`does(e)` 以及对应的过去时形式。

### 信念、目标、意图的可达世界

在每个情景上：

- **信念可达世界**：Agent 认为可能的那些世界。与常见信念模型不同，这里每个可达世界本身仍是一棵时间树：多世界来自对当前状态的无知；世界内部的分支则是 Agent 仍可选择的行动。
- **目标可达世界**：表示已选定的目标。目标必须一致；并且采用 **strong realism**：Agent 须相信通过审慎选择事件（由自己或他者执行），目标可以可选地达成。实现方式是：对当前的每个信念可达世界 \(w\)，在同一时刻必须存在一个目标可达世界，它是 \(w\) 的**子世界**。
- **意图可达世界**：Agent 已承诺去尝试实现的世界。兼容条件平行：每个目标可达世界在同一时刻必须有一个作为其子世界的意图可达世界。直观上，Agent 在目标世界里进一步选出一条行动路径并承诺去尝试。

反之不成立：即使 Agent 相信某事实不可避免，也不被迫把它收成目标或意图。因此目标与意图须一致，但**不必在信念下封闭**。文中的例子：Agent 相信「补牙不可避免伴随疼痛」，仍可以有「去补牙」的目标（与意图），而不必有「去疼痛」的目标（与意图）。这用来避开副作用被强制承诺的问题。

把上述图景比作决策树：机会节点伸出的弧对应不同可能世界，决策节点伸出的弧对应同一世界内的选择。

1991 年论文的第 3 节给出解释 \(M = \langle W, E, T, \ldots, B, G, I, \Phi \rangle\) 与满足关系；第 4 节讨论态度如何形成、维持、修正，以及不同承诺策略如何改变行为。承诺策略的直观分类在后续 BDI 文献中稳定为三类（1995 年实践论文中写得更便于实现对照）：

| 策略 | 放弃意图的条件 |
| --- | --- |
| 盲目承诺（blind / fanatical） | 直到相信已成功，或相信已不可能 |
| 一心一意（single-minded） | 上述条件，或目标本身已被放弃 |
| 开放（open-minded） | 信念变化导致目标不再成立时也可以放弃 |

### 从理论到解释器（1995）

1995 年 *BDI Agents: From Theory to Practice* 给出与上述语义对应的解释器循环，便于把形式对象落到数据结构。过程可以写成：

```text
初始化状态
重复：
  选项 := 根据事件队列生成选项
  选定 := 对选项做慎思（deliberate）
  用选定结果更新意图
  执行当前意图中的一步
  获取新的外部事件
  丢掉已成功的态度
  丢掉已不可能的态度
```

这里「选项」对应可采纳的手段，「慎思」对应从愿望中筛选意图，「执行」对应对已承诺计划采取一步行动。事件队列把环境观察接进信念修正。这一循环是 BDI **作为软件架构**时最常被引用的部分；1991 年论文则是其语义依据。

## 关键术语

| 术语 | 在这篇论文里的含义 |
| --- | --- |
| 信念可达世界 | Agent 认为可能的时间树集合 |
| 目标 vs 愿望 | 目标是一致的、且被相信可达成的选定愿望 |
| 意图 | 已承诺尝试实现的部分计划；与信念、目标平级 |
| 子世界兼容 | 目标是信念的子世界，意图是目标的子世界 |
| strong realism | 须相信目标可通过选择行动可选地达成 |
| 承诺策略 | 意图在成功、失败、目标变化、信念变化时如何持续 |
| 副作用问题 | 相信「φ 蕴含 ψ」时，对 φ 的意图是否强制带上 ψ |

## 和 AI Agent 的关系

LLM 产品里出现的 memory、goal、plan、todo，与 BDI 三态度在**问题上**对应：系统对世界有一个当前看法，有一个要达成的目标，有一个正在执行、不应每步都推翻的计划。在**实现上**不对应：没有可能世界可达关系，也没有上述解释器里那种形式化的选项生成与承诺策略。上下文窗口、检索、频道记忆承担的是信念的工程替代；系统提示或用户请求承担的是目标；运行时任务列表承担的是意图。

[MemGPT](/agents/memgpt/) 处理的是上下文窗口长度，不是 BDI 的信念修正公理。本页不把「长期记忆」写成 BDI 的复活。

单是动作序列、不含心智态度的规划见 [STRIPS](../strips/)。1995 年如何把 BDI 放进 Agent 理论条目，见 [Wooldridge & Jennings](../wooldridge-jennings/)。本笔记为何仍把 BDI 标为前传，见 [什么不是 AI Agent](/definition/what-is-not-ai-agent/)。
