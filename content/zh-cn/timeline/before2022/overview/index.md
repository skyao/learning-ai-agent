**主线判断：** Agent 作为研究纲领，比大语言模型早几十年；规划、工具、多 Agent 通信这些概念都不是 2023 年发明的。真正缺少的，是一个能在开放语言空间里做出决策的核心。2017 至 2021 年，Transformer、GPT-3 与 Codex 把底层能力铺好，但循环、对话接口与可靠的调用解析都还没有齐备——符合 AI Agent 定义的系统，此时并不存在。

我在这一页有意写得比一部 AI 通史短。专家系统、具身机器人、自动驾驶不进入主线；强化学习游戏 Agent 只用于指出词汇上的重叠。需要核对的是两段：**经典 Agent 留下了哪些概念**，以及 **LLM 在跨过 2022 年之前已经具备哪些前提、仍然缺少哪些**。

## 与 LLM 的关系

2022 年之前，这段关系要拆成两截，不能混在一起讲。

**1990 年代到 2010 年代：决策核心不是语言模型。** 经典 Agent 用符号规划器、产生式规则、BDI（信念—愿望—意图）或强化学习策略来选择下一步动作。环境是结构化的（棋盘、传感器、API 表、对话槽位），不是自由文本。它们完全符合「感知—决策—行动」的教科书定义，也因此占用了 Agent 这个词；但按 AI Agent 的定义，它们不是 LLM Agent，因为缺少第一条：以 LLM 作为决策核心。

**2017 至 2021 年：底层能力开始出现，产品形态仍不是 Agent。** Transformer（2017）与 GPT-3（2020）证明，足够大的语言模型可以在上下文里完成从未见过的任务。Codex（2021）把这种能力接到代码上，GitHub Copilot 把它做成行级补全。WebGPT（2021）让模型在文本浏览器里检索、点击、引用之后再作答。这些都是后来 Agent 循环的零件——生成、工具、检索、代码，但当时仍是**单次或短链调用**，不是「给出一个目标，自行迭代到完成」。指令跟随（InstructGPT）的工作贯穿 2021 年，其论文与默认 API 跨入 2022 年初；真正把「听话的对话模型」送到大众面前的，是 2022 年 11 月的 ChatGPT。

因此前传要回答的不是「Agent 诞生于哪一年」，而是：**概念库存早已齐备，缺少的是一个能读自然语言、选择工具、并依据回执改变主意的决策核心；这个决策核心在 2021 年底仍只能完成短任务。** 核未就绪，控制流、schema 与沙箱都无从挂载。

## 里程碑

分两段记录。第一段是概念库存，第二段是 LLM 底层能力。底层能力每条给出一个**分类**，**标签**可以有多个（[六类历史角色](../../overview/research/#里程碑类型)）。经典文献多数属于**首证**，或为后来提供了词汇，不应写成 LLM Agent 的祖先产品。

### 概念库存：词汇的来源

各条分别写在 [早期概念](../early-concepts/) 中，本表只保留判断。

| 时间 | 事件 | 类型 | 为什么记录 |
| --- | --- | --- | --- |
| 1971 | [STRIPS](../early-concepts/strips/)（Fikes & Nilsson） | 首证 | 把世界写成谓词，用算子搜索计划。后来 Agent 里的 Planning，其古典形态就是这一支。控制流在规划器，不在语言模型 |
| 1980 | [Contract Net Protocol](../early-concepts/contract-net/)（Smith） | 首证 | 任务招标、投标、授予：多 Agent 分工的早期协议。它与 2025 年的 [A2A](/protocal/a2a/) 不是同一套技术，但说明「Agent 之间如何对话」是一个老问题，协议可以先于生态 |
| 1986 | [Brooks 包容架构](../early-concepts/subsumption/) | 警示 / 首证 | 主张智能来自与环境的耦合，而不是先建立完整的世界模型。并非所有 Agent 路线都走「先推理再行动」 |
| 1991 | [BDI](../early-concepts/bdi/)（Rao & Georgeff） | 首证 | 用信念、愿望、意图描述理性 Agent。今天产品里的 goal、plan、memory 常是这套词汇的口语版本，实现已经更换。决策核心是符号，不是 LLM |
| 1995 | [Wooldridge & Jennings](../early-concepts/wooldridge-jennings/), *Intelligent Agents: Theory and Practice* | 工程化 | 把理论、架构、语言三块分开讨论，是「什么算 Agent」的常用入口，不是一篇模型论文 |
| 1995 | [Russell & Norvig](../early-concepts/russell-norvig/)《人工智能：一种现代方法》第一版 | 工程化 | 用「理性 Agent」统摄教材：感知、行动、环境、性能度量。后来人们普遍使用 Agent 一词，很大程度上来自这里。教材定义宽于本站的工作定义 |
| 1996 起 | [FIPA 与 ACL](../early-concepts/fipa-acl/) | 标准 | 试图规定 Agent 通信语言与工作流。生态没有长成后来的互联网协议。标准可以先于生态，也可以因缺少生态而终止 |
| 2011–2014 | [Siri / Alexa / 任务型对话](../early-concepts/task-oriented-dialogue/) | 工程化 | 槽位填充加后端 API，是大规模的「语音助手」。循环由状态机驱动，控制图在上线前就已闭合，不是 LLM 规划；它说明大众对「助手」的想象早于 ChatGPT |

刻意不展开的有：ELIZA（1966，对话幻觉的前史）、办公助手、语义网 Agent，以及绝大多数专家系统。它们可以说明「会说话不等于 Agent」，但带不走本站的主线。

### 相邻领域，仅作消歧

| 时间 | 事件 | 为什么只点名 |
| --- | --- | --- |
| 2013–2019 | DQN、AlphaGo、OpenAI Five、AlphaStar | 媒体也称它们为 Agent。决策核心是 RL 策略，环境是游戏或棋局。体系与软件 LLM Agent 不同，不进入主叙事 |
| 机器人 / 自动驾驶 | 感知—控制闭环 | [调研方法](../../overview/research/) 已划为相邻领域 |

判定标准只有一条：决策核心是否为语言模型。不是，则不进入主叙事。

### LLM 底层能力：零件出现，循环未成

| 时间 | 事件 | 分类 | 标签 | 为什么记录 |
| --- | --- | --- | --- | --- |
| 2017-06 | [Transformer](../transformer/)（[论文](../transformer/paper/)、[讲解](../transformer/explanation/)） | 论文 | 范式更替 | 用自注意力替代循环与卷积，成为后续 LLM 的骨架。没有可扩展的条件生成器，后面就没有可讨论的决策核心。它不包含工具，也不包含终止条件 |
| 2020-05 | [GPT-3](../gpt-3/)（[论文](../gpt-3/paper/)、[讲解](../gpt-3/explanation/)） | 模型 | 首证 | 上下文学习：不更新权重也能做新任务。Agent 后来把 Observation 当作工作记忆，其物理前提从这里开始。当时窗口约 2k–4k，工具调用只能依赖模型吐出可解析的字符串 |
| 2020-05 | [RAG](../rag/)（[论文](../rag/paper/)、[讲解](../rag/explanation/)） | 论文 | 工程化 | 生成之前先检索。后来几乎所有「带外部知识的 Agent」都要先经过这一步；它本身仍是单次流水线，不是迭代循环 |
| 2021-06 | [GitHub Copilot](../github-copilot/)（[材料](../github-copilot/source/)、[讲解](../github-copilot/explanation/)） | 产品 | 工程化 | 把 Codex 的能力做成 IDE 补全。按 AI Agent 定义**不是** Agent（无自主目标，无多步环境循环），但它是「Copilot → Agent」这条演化的起点。副作用在编辑器缓冲区，不在环境；无目标环 |
| 2021-07 | [Codex](../codex/)（[论文](../codex/paper/)、[讲解](../codex/explanation/)） | 模型 | 首证 | 语言模型写出可运行的代码。没有代码生成，就不会有后来的编码 Agent。生产版本驱动 GitHub Copilot。核不是运行时 |
| 2021-07 | [HumanEval](../humaneval/)（[论文](../humaneval/paper/)、[讲解](../humaneval/explanation/)） | 评测 | 首证、标准 | 用单元测试衡量函数级合成。完成谓词的早期形态：看执行结果，不看流畅度。覆盖面远窄于 2023 年的 SWE-bench |
| 2021-12 | [WebGPT](../webgpt/)（[论文](../webgpt/paper/)、[讲解](../webgpt/explanation/)） | 产品 | 首证 | GPT-3 在文本浏览器里检索、导航、带引用作答，并用人类反馈优化。这是「模型加环境加工具」的实验室形态；目标仍是答好一道题，不是自主完成开放任务。通道是页面，谓词是答题 |

这一段的共同限度：上下文窗口大约 2k–4k，指令跟随尚不稳定，没有结构化的 function calling schema，也没有工具描述的可移植格式——WebGPT 的动作表写在论文里，不是可传递的产物；更没有大众可用的多轮对话产品。零件齐备，控制循环、可解析接线与可对话接口都未齐备。

## 能力栈切片

用本站的四层结构去看「当时有什么、没有什么」，避免把 2023 年的分层倒灌回去。

### 模型层

经典 Agent 没有「模型层」这一说，决策是规则或学到的策略。LLM 出现之后，2021 年底的能力边界大致是：能补全，能少样本模仿，能写短函数，能在受控浏览器里查资料。不能稳定地拆解开放目标，不能在失败之后修改计划，不能把工具调用解析成可靠的 JSON。思维链要到 2022 年才被当作可复现的推理协议。核是条件生成器，还不是规划器。

### 框架 / 协议层

经典一侧有规划语言（[STRIPS](../early-concepts/strips/) 及后来的 PDDL）、Agent 通信语言（[FIPA ACL](../early-concepts/fipa-acl/)）、[BDI](../early-concepts/bdi/) 解释器。它们假设世界模型与言语行为可以被形式化。LLM 一侧在 2021 年还没有编排框架：没有 LangChain，没有 MCP，没有 Assistants API。WebGPT 的浏览器是论文里的环境，不是可插拔协议。

一个对后面有用的对照：FIPA 证明「先写协议、再等生态」可以失败；2024 至 2025 年的 MCP 与 A2A 走的是「先有模型产品，再收敛为事实标准」。Framework、Runtime 与 Protocol 三者此时在 LLM 一侧都还不存在。

### 应用层

能够规模化的是助手，不是自主执行。任务型对话（订机票、查天气）与 Copilot 补全都是人在循环、一步一确认。WebGPT 与 Codex 停留在研究或开发者工具。没有「给出一个目标，让它在工具与环境里自行运转到完成」的产品，而那正是 2023 年 AutoGPT 所宣称要占据的位置。

### 基础设施层

沙箱、长任务调度、组织级身份都不存在，因为还没有会乱执行命令的 LLM 循环需要被约束。评测停留在语言任务、HumanEval 与检索问答。记忆等于对话状态机或数据库槽位，不是窗口加向量库那一套。站点中后来的记忆、沙箱栏目，都是 2023 年之后才成为 Agent 基础设施的。主体（principal）无从谈起。

## 当时还做不到什么

到 2021 年 12 月 31 日，按 AI Agent 的定义，下面这些都不成立：

- **以 LLM 作为循环里的决策核心。** 模型能生成下一步文本，但不能稳定地「想—做—看—再想」。控制流不在模型的输出里。
- **开放目标上的自主执行。** 助手能填槽，Copilot 能补一行；没有系统在无人看管时把一件事做到可交付。缺少目标终止条件。
- **可对话的通用接口。** GPT-3 是 playground 与 API，不是后来那种人人会用的 Chat。
- **结构化的工具调用。** 要让模型使用工具，就得在 prompt 里依赖它吐出可解析的格式。没有 schema，就没有稳定的接线。
- **支撑长任务的上下文。** 窗口太短，「当前观察」装不进多少环境回执。工作集不足。
- **任务型评测。** 没有 SWE-bench、GAIA、OSWorld；HumanEval 只覆盖函数级合成。完成谓词尚未接到仓库或桌面。

当时若有人宣称「自主 Agent」，多半是在说 BDI、机器人或强化学习，而不是在说 LLM。
