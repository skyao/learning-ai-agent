**一句话主线：** Agent 作为研究纲领比大语言模型早几十年；规划、工具、多 Agent 通信这些词都不是 2023 发明的。缺的是一个能在开放语言空间里做决策的核。2017–2021 年 Transformer / GPT-3 / Codex 把这块底物铺上，但循环、对话接口和可靠工具调用都还没齐——本站要讲的 LLM Agent，此时还不存在。

总弧线见 [概述](../overview/)，对象边界见 [调研方法](../overview/research/)。下一年：[2022](../2022/)。

这一页有意写短于一部 AI 通史。专家系统、具身机器人、自动驾驶不进主线；强化学习游戏 Agent 只点到「词的重叠」。要记住的是两段：**经典 Agent 留下了哪些概念**，以及 **LLM 在跨过 2022 之前已经具备哪些前提、仍缺哪些**。

## 和 LLM 的关系

2022 年之前，这段关系要拆成两截，不能混着讲。

**1990 年代到 2010 年代：决策核不是语言模型。** 经典 Agent 用符号规划器、产生式规则、BDI（信念—愿望—意图）或强化学习策略选下一步动作。环境是结构化的（棋盘、传感器、API 表、对话槽位），不是自由文本。它们完全符合「感知—决策—行动」的教科书定义，也因此占用了 Agent 这个词；但按本站工作定义，它们不是 LLM Agent，因为缺第一条：LLM 为核心决策模块。

**2017–2021：底物开始出现，产品形态还不是 Agent。** Transformer（2017）和 GPT-3（2020）证明：足够大的语言模型可以在上下文里完成从未见过的任务。Codex（2021）把这种能力接到代码上，GitHub Copilot 把它做成行级补全。WebGPT（2021）让模型在文本浏览器里搜索、点击、引用后再回答。这些都是后来 Agent 循环的零件——生成、工具、检索、代码——但当时仍是**单次或短链调用**，不是「给一个目标，自己迭代到完成」。指令跟随（InstructGPT）的工作贯穿 2021、论文和默认 API 跨入 2022 年初，真正把「听话的对话模型」送到大众面前的是 2022-11 的 ChatGPT。细节放到 [2022](../2022/)。

所以前传要回答的不是「Agent 哪年诞生」，而是：**概念库存早已齐备，缺的是一个能读自然语言、选工具、根据回执改主意的决策核；这个核在 2021 年底仍只能做短任务。**

## 里程碑

分两段记。第一段是概念库存，第二段是 LLM 底物。类型仍按 [六类](../overview/research/#里程碑类型)；经典文献多数是**首证**或给后来提供词汇，不要事后追认成 LLM Agent 的祖先产品。

### 概念库存：词从哪里来

| 时间 | 事件 | 类型 | 为什么记 |
| --- | --- | --- | --- |
| 1971 | STRIPS（Fikes & Nilsson） | 首证 | 把世界写成谓词，用算子搜索计划。后来 Agent 里的 Planning，古典形态就是这一支 |
| 1980 | Contract Net Protocol（Smith） | 首证 | 任务招标、投标、授予：多 Agent 分工的早期协议，和 2025 年 [A2A](/protocal/a2a/) 不是同一套技术，但说明「Agent 之间怎么说话」是老问题 |
| 1986 | Brooks 包容架构 | 警示 / 首证 | 主张智能来自与环境的耦合，而不是先建完整世界模型。提醒：不是所有 Agent 路线都走「先推理再行动」 |
| 1991 | BDI（Rao & Georgeff） | 首证 | 用信念、愿望、意图描述理性 Agent。今日产品里的 goal / plan / memory 常是这套词的口语版，实现已经换了 |
| 1995 | Wooldridge & Jennings, *Intelligent Agents: Theory and Practice* | 工程化 | 把理论、架构、语言三块分开讲，是「什么算 Agent」的常用入口，不是一篇模型论文 |
| 1995 | Russell & Norvig《人工智能：一种现代方法》第一版 | 工程化 | 用「理性 Agent」统摄教材：感知、行动、环境、性能度量。后来人人会说 Agent，很大程度来自这里 |
| 1996 起 | FIPA 与 ACL | 标准 | 试图规定 Agent 通信语言和工作流。生态没有长成后来的互联网协议；读 [A2A](/protocal/a2a/) 时值得对照：标准可以先于生态，也可以死于无生态 |
| 2011–2014 | Siri / Alexa / 任务型对话 | 工程化 | 槽位填充 + 后端 API，是大规模「语音助手」。循环由状态机驱动，不是 LLM 规划；说明大众对「助手」的想象早于 ChatGPT |

刻意不展开的：ELIZA（1966，对话幻觉的前史）、办公助手、语义网 Agent、绝大多数专家系统。它们能说明「会说话 ≠ Agent」，但带不走本站主线。

### 相邻领域，只为消歧

| 时间 | 事件 | 为什么只点名 |
| --- | --- | --- |
| 2013–2019 | DQN、AlphaGo、OpenAI Five、AlphaStar | 媒体也叫 Agent。决策核是 RL 策略，环境是游戏或棋。体系与软件 LLM Agent 不同，不进主叙事 |
| 机器人 / 自动驾驶 | 感知—控制闭环 | [调研方法](../overview/research/) 已划为相邻领域 |

读到这些词时，问一句：决策核是不是语言模型？不是，就停。

### LLM 底物：零件出现，循环未齐

| 时间 | 事件 | 类型 | 为什么记 |
| --- | --- | --- | --- |
| 2017-06 | [Attention Is All You Need](https://arxiv.org/abs/1706.03762) | 范式更替 | Transformer 成为后续所有 LLM 的骨架。没有它，后面没有决策核可谈 |
| 2020-05 | [GPT-3](https://arxiv.org/abs/2005.14165)（Brown et al.） | 首证 | 上下文学习：不更新权重也能做新任务。Agent 后来把「当前观察塞进窗口」当成工作记忆，物理前提从这里开始 |
| 2020-05 | [RAG](https://arxiv.org/abs/2005.11401)（Lewis et al.） | 工程化 | 生成之前先检索。后来几乎所有「有外部知识的 Agent」都先经过这一刀；它本身仍是单次流水线，不是迭代循环 |
| 2021-06 | GitHub Copilot 技术预览 | 工程化 | 把 Codex 能力做成 IDE 补全。按本站定义**不是** Agent（无自主目标、无多步环境循环），但是「Copilot → Agent」这条演化的起点 |
| 2021-07 | [Codex / HumanEval](https://arxiv.org/abs/2107.03374) | 首证 | 语言模型写出可运行代码，并用单元测试打分。没有代码生成，就不会有后来的编码 Agent；HumanEval 也是评测意识的早期形态，远窄于 2023 的 SWE-bench |
| 2021-12 | [WebGPT](https://arxiv.org/abs/2112.09332) | 首证 | GPT-3 在文本浏览器里搜索、导航、带引用作答，并用人类反馈优化。这是「模型 + 环境 + 工具」的实验室形态；目标仍是答好一道题，不是自主完成开放任务 |

这一段的共同限度：上下文窗口大约 2k–4k，指令跟随还不稳，没有结构化 function calling，没有大众可用的多轮对话产品。零件在，机器没有装起来。

## 能力栈切片

用本站四层去看「当时有什么、没有什么」，避免把 2023 的分层倒灌回去。

### 模型层

经典 Agent 没有「模型层」这回事，决策是规则或学到的策略。LLM 出现后，2021 年底的能力边界大致是：能补全、能少样本模仿、能写短函数、能在受控浏览器里查资料。不能稳定地拆开放目标、不能在失败后改计划、不能把工具调用解析成可靠的 JSON。思维链要到 [2022](../2022/) 才被当成可复现的推理协议。

### 框架 / 协议层

经典侧有规划语言（STRIPS / 后来的 PDDL）、Agent 通信语言（FIPA ACL）、BDI 解释器。它们假设世界模型和言语行为可以被形式化。LLM 侧在 2021 还没有编排框架：没有 LangChain，没有 MCP，没有 Assistants API。WebGPT 的浏览器是论文里的环境，不是可插拔协议。

一个对后面有用的对照：FIPA 证明「先写协议再等生态」可以失败；2024–2025 的 MCP / A2A 走的是「先有模型产品，再收成事实标准」。读协议栏目时带着这个差异。

### 应用层

能规模化的是助手，不是自主执行。任务型对话（订机票、查天气）和 Copilot 补全都是人在环、一步一确认。WebGPT 和 Codex 停在研究或开发者工具。没有「给一个目标，让它自己在工具和环境里转完」的产品——那是 [2023](../2023/) 的 AutoGPT 幻想所接的位置。

### 基础设施层

沙箱、长任务调度、组织级身份都不存在，因为还没有会乱执行命令的 LLM 循环需要被关起来。评测停在语言任务、HumanEval、检索问答。记忆等于对话状态机或数据库槽位，不是窗口 + 向量库那一套。站点里后来的 [记忆](/infra/context/memory/)、[沙箱](/infra/environment/sandbox/) 都是 2023 之后才成为 Agent 基础设施。

## 还做不到什么

到 2021 年 12 月 31 日，按本站定义，下面这些都不成立——这正是 [2022](../2022/) 和 [2023](../2023/) 要补的缺口：

- **LLM 作为循环里的决策核。** 模型能生成下一步文本，但不能稳定地「想—做—看—再想」。
- **开放目标上的自主执行。** 助手能填槽，Copilot 能补一行；没有系统在无人盯着时把一件事做到可交。
- **可对话的通用接口。** GPT-3 是 playground 和 API，不是后来那种人人会用的 Chat。
- **结构化工具调用。** 要模型用工具，就得在 prompt 里赌它吐出可解析的格式。
- **撑住长任务的上下文。** 窗口太短，「当前观察」塞不进多少环境回执。
- **任务型评测。** 没有 SWE-bench、GAIA、OSWorld；HumanEval 只覆盖函数级合成。

当时若有人宣称「自主 Agent」，多半是在说 BDI、机器人或 RL，不是在说 LLM。把 2023 的热度倒填进 2020，属于事后归因。

## 怎么学 / 往哪跳

前传的读法是**借词、不借实现**：

1. 用 Russell & Norvig 的四元组（感知、行动、环境、性能度量）和本站四要素对打：经典定义覆盖前三个动作要素，本站多要求「LLM 当决策核」。分清之后，后面年份不会把 Siri 和 Claude Code 算成一类。
2. 扫 BDI 和 FIPA 的摘要即可，不必读完形式语义。问：goal / plan / 通信这些词，后来在 LLM 循环里分别变成了 prompt、工具、消息协议的哪一层。
3. 读 GPT-3 和 Codex 的摘要，只记两句：上下文是工作记忆的物理上限；代码生成是编码 Agent 的前提，Copilot 还不是 Agent。
4. 读 [WebGPT](https://arxiv.org/abs/2112.09332) 的环境描述（搜索、点击、引用），再去 [2023](../2023/) 看 ReAct。前者是「为答一题而浏览」，后者是「边想边做的通用循环」。
5. 需要协议对照时打开 [A2A](/protocal/a2a/)：先知道 1990 年代已经试过 Agent 通信标准，再看 2025 年为什么旧事重提、实现却完全不同。

读完这一页，应能回答：为什么不能说「Agent 诞生于 2023」，以及为什么又必须说「LLM Agent 的主线从 2022 才开始」。下一页补齐对话接口和思维链，循环要到 2023 才被工程化。
