## 这个产品解决了什么问题

[Codex](../../codex/) 证明模型能写出过单测的函数。日常开发更窄：**光标已在文件里，下一行或下一个函数是什么。** Copilot 把这一步收成编辑器内建议。产品没有新学习算法；它发明的是交付位置：VS Code 光标处、可循环的候选、人决定接受。技术预览选 Python / JS / TS / Ruby / Go，是因为这些语言上生成当时更稳。

人在循环是产品定义，不是缺陷描述。失败由人改提示或手写。按 AI Agent 定义，这不是 Agent。

## 对后续 LLM 的影响

代码模型第一次有大规模日活界面。反馈（接受 / 拒绝）后来成为改进补全的产品数据；接口从 2021-06 起就在。「提示」变成当前文件：GPT-3 的 few-shot 是刻意拼的示范；Copilot 的条件是打开的缓冲区、注释、函数名。上下文学习从论文设定变成默认 IDE 行为。

「Copilot」一词被占住。之后 Microsoft 365 Copilot、GitHub Copilot Chat、各种「X Copilot」都借用副驾驶隐喻。2021 年的所指仍是补全，不是自主执行。

## 对 AI Agent 的影响

时间线标成底层能力里的**工程化**：有副作用，无目标环。演化写在交付位置的变化上，不把 2023 写回 2021。

| 2021 技术预览 | 后来编码 Agent 多出来的东西 |
| --- | --- |
| 当前文件上下文 | 仓库、终端、浏览器、issue |
| 建议一行 / 一个函数 | 多文件补丁、命令、测试 |
| 人立刻接受或拒绝 | 循环里根据测试回执再改 |
| 无自主目标 | 有任务目标（修 bug、实现规格） |

副作用发生在编辑器缓冲区：插入或替换文本。观察等于当前缓冲区。没有「做到某个外部谓词为真」的终止条件。它不是 Agent，但是「Copilot → Agent」这条产品线的起点。
