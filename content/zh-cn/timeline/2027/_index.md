**一句话主线：** 现在是 2026 年 9 月。这一页不是年表，是**观察提纲**——顺着 2024–2026 已经露出的缺口，列出值得盯的方向。厂商路线图、未交付的 JIT 凭证、未铺开的 Slack 之外表面，一律当假设，不当事实。有了一手来源（论文、官方公告、可复现仓库）再升格进里程碑表。

上一页：[2026](../2026/)。采信门槛见 [调研方法](../overview/research/)。总弧线见 [概述](../overview/)。

## 和 LLM 的关系（观察，不是结论）

2026 已经把矛盾推到模型之外。2027 仍可能被模型层再改写一次，但只有改写了 **Agent 能做什么的前提** 才值得记进主线，例如：

- 长程可靠性是否从「偶尔跨天」变成「默认可跨天」（失败模式、回放、可停可续）。
- 推理成本是否降到让组织敢把 ambient / routine 开满，而不是只给编码开。
- 是否出现真正的 **Agent 专用模型**（为工具循环、电脑操作、组织身份训练），而不只是通用核 + 运行时套件。
- 多模态操作（屏幕、内部网页、设计稿）的可靠度，是否逼近 2025–2026 编码线已经达到的「能交 PR」。

这些在没有分数、没有复现、没有持续产品行为之前，只是问题，不是里程碑。

## 建议盯住的线索

按本站六类，**预先分类「如果发生，它算哪一种」**，避免到时候被通稿带着走。

### 身份与权限（接 2026 Tag / Agent Identity）

- **JIT 凭证：** 用户当场批准一次敏感动作，而不永久扩大 agent scope。来源线索：身份博文的「What's next」。有 API、有审计日志再记 **工程化**；只有 keynote 不算。
- **身份叠加：** 频道 profile ∩ 请求者本人权限。这会部分收回 2026「频道成员共享同一 bundle」的激进模型，可能是 **范式更替**，也可能只是 Enterprise 开关。
- **非 Slack 表面：** 同一套组织身份出现在文档、工单、IDE、邮件。那是 Tag「从 Slack 起步」这句话有没有兑现。算 **工程化**，不要提前写成已经全公司打通。

### 协议与运行时（接 MCP / A2A / Skills / Code 运行时）

- MCP 是否还是工具层默认方言，还是被下一代协议换掉。换掉才是 **标准** 事件；多几个 server 不算。
- A2A 有没有从发布会走进可互操作的生产（发现、鉴权、失败处理）。对照 [前传 FIPA](../before2022/)：标准可以先于生态，也可以死于无生态。
- Skills 是否成为跨运行时的专长格式，还是锁在一家模型厂商。
- 终端运行时（Claude Code / Codex CLI 等）与团队运行时（Tag）是否共用配置、身份、评测，还是继续分叉。

### 基础设施（接 Aries / SpecBox / 沙箱生命周期）

- 沙盒预热、推测调度、带外传输，有没有从论文变成云厂商默认。那是 **工程化**。
- Agent 负载的计费与隔离，是否从「按 token」补上「按沙箱·分钟 / 按出站」。经济性维度会第一次压过智力维度。
- 自托管 runner 能否用上组织级 Access bundle（2026 文档里还不行）。

### 评测与证伪（接 SWE-bench / OSWorld）

- 出现「团队任务」基准：多驾驶员、异步、带权限边界——而不只是单仓库 issue。
- 某一路线被公开证伪：例如纯 GUI 电脑操作长期达不到编码线，产品退回 API/MCP；或纯多 Agent 编排再次证明不如单运行时 + 好工具。这类记 **证伪/警示**，和 2023 泡沫同等重要。
- 刷榜与真实留存继续分叉。只报 SWE-bench、不报回滚率的，维持 2024 的打折读法。

### 应用形态

- 研究型 Agent、编码 Agent、电脑操作、团队频道：四条线是收敛进一个入口，还是继续分产品。
- 监管与合规（训练数据、行动审计、行业准入）若开始决定「能不能部署」，那是主线，不是附录。

## 还没有资格写进年表的

## 怎么用这一页学习

不要等 2027 年底再读。建议：

1. 每遇到一条新闻，先丢进上面某一类线索，再问 [六类里程碑](../overview/research/#里程碑类型) 和 [采信门槛](../overview/research/#采信门槛)。
2. 一手来源进 [资料](/data/) 的当年目录；时间线只加一行表 + 类型 + 「当时热度 vs 可能的后世重要性」。
3. 和 2026 对照着读：身份、沙箱、团队表面这三件事，哪一件真的动了。

页脚可以随学习往下加「已确认事件」小节。在那之前，这一页保持为提纲。
