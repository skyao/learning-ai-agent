## 当时解决了什么问题

论文和推上已经有 self-ask、搜一下、算一下、先想再答。每做一个演示就要重写提示词、重接 API、重解析输出。LangChain 把这些收成 Chain：同一套 LLM 包装，换搜索或换数学链。成本从「读论文再手搓」降到 `pip install`。

它不是新推理算法，也不是把循环写进论文的那种协议——同月的 ReAct 挂在 arXiv 上，库的第一批例子甚至还没有以 ReAct 为名。它是工程上的**默认拼法**。

## 对后续 LLM 与 Agent 的影响

ChatGPT 一个月后放出，人人要「自己接工具」。现成胶水成为默认入口，2023 年的 Agent 教程大量从 LangChain 抄起。后来的批评（抽象过重、版本不稳）针对的是膨胀期，不能用来否定 2022 秋那三条目的：组合、链、可分享。公司 2023-02 成立，产品史从那里分叉；今年只记生日。
