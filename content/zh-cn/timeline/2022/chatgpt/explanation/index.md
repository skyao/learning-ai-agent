## 当时解决了什么问题

[InstructGPT](../../instructgpt/) 已经让 API 默认跟指令。普通用户没有 Playground，也没有「系统消息 + few-shot」的工程师习惯。ChatGPT 把同一套对齐做成**对话框**：多轮、可纠正、可拒绝，网址即可用。数据侧的关键差别是双向对话演示，以及把指令数据改成对话格式——对象从「一次性完成指令」变成「接着聊」。

它解决的是入口和交互习惯，不是工具、不是沙箱、不是任务闭环。幻觉、冗长、对措辞敏感，公告自己写在限度里。

## 对后续 LLM 的影响

「对着一个会多轮改主意的 LLM 说话」变成默认人机界面。2023 年所有系统提示、Chat Completions、后来的 Agent 对话框，都假定用户已经会用这种界面。GPT-3.5 这个名字也从这里进入大众词汇。规模与对齐过的对话模型，从此不再只是论文数字。

## 对 AI Agent 的影响

按 AI Agent 定义，ChatGPT **不是** Agent：没有对环境的行动循环，观察等于用户下一句，行动等于再生成一句。它改变的是**谁会来用决策核心**。2022 年舆论中心是 ChatGPT，不是交错行动的论文——时间线必须分开记，不能用后世重要性把 11 月的产品写成已经在执行任务。
