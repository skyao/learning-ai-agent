## 论文解决了什么问题

[GPT-3](../../../before2022/gpt-3/) 已经证明规模带来上下文学习，默认行为仍是**补全互联网文本**。用户写「写一封道歉信」，模型可能继续写成网页上的随机后文，而不是完成指令。这不是提示词写得不够巧就能彻底消掉的：目标函数与「有帮助、真实、无害地办事」不一致。

InstructGPT 把适应方式从「拼 few-shot」改成 **改权重**：演示（SFT）给出格式，比较数据训出「人更喜欢哪一个」，PPO 把策略推过去。1.3B 对齐后的模型在作者的提示分布上胜过未对齐的 175B，说明**意图对齐不是参数量的免费附赠**。

论文对象是 API 上的指令跟随，不是多轮产品，也不是工具循环。ChatGPT 把同一套 RLHF 接到对话数据上，是十个月后的入口。

## 对后续 LLM 的影响

指令跟随成为默认接口：系统消息、开发者提示、「你是某某助手」，都假定模型会把文本当任务而不是当续写。FLAN / T0 走的是公开 NLP 任务混合；InstructGPT 证明**真实用户提示分布**上，人类偏好数据更对口。对齐税（公开基准掉分）也从此成为训练配方里的常规项（PPO-ptx 一类补丁）。

## 对 AI Agent 的影响

Agent 的决策核心必须听得懂目标陈述。没有指令跟随，轨迹、工具 schema、系统提示都会被模型当成又一段网页。它仍然不是 Agent：一次生成一段回复，没有环境行动循环。2022-01 的工程化含义是：后面所有「对模型下指令」的产品，都踩在这条对齐过的核心上。
